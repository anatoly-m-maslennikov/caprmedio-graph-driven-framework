# Resolve Project Configuration and the Scope Unit Graph separately

CAPRMEDIO skills resolve Project Configuration through the governed external binding for `atom_id: CAPRMEDIO-I-001` **and** its native Carrier locator, **and** resolve the Project Scope Unit Graph through its registered generated Projection addresses, **without** substituting a Projection for configuration authority **or** treating the Configuration Atom as derived graph state.
