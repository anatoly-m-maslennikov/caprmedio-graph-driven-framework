# Serialize CCE Operators in Bold

**every** CCE Operator occurrence within Markdown Main Content **must** use its exact canonical spelling with bold rendering; a word-form CCE Operator **must** use lowercase bold text, while a symbolic CCE Operator **must** use bold inline-code rendering.
