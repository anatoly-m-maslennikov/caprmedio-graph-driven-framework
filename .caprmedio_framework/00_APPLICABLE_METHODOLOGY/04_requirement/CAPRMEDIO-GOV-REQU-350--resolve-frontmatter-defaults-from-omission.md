# Resolve frontmatter defaults from omission

GOVERNANCE registers every frontmatter default with its applicability boundary. Writers omit a property when its resolved value equals the applicable default, readers resolve that omission from the same authority, validators reject redundant persisted defaults, and omission means absence when no applicable default exists.
