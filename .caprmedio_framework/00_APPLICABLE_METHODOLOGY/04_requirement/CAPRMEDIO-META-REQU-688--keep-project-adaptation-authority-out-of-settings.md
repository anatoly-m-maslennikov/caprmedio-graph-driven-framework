# Keep Project Adaptation authority out of settings

Project Adaptation **and** Extension meaning **must** be owned by their applicable Atoms. The Project Configuration Atom **may** select, disable, **and** parameterize them, **and** Project Scope Unit Graph Projections **may** expose the effective result, but Project Configuration **and** Project Scope Unit Graph Projection **must not** redefine **or** amend their governed meaning.
