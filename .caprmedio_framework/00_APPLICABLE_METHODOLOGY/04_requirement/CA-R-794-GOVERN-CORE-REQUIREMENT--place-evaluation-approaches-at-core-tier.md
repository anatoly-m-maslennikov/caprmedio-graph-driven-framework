# Distinguish Core evaluation policy from Standard checks

an Evaluation Atom that governs evaluation policy **or** general case-building criteria for the full current Scope **must** occupy Local Tier Core; a concrete check **or** test case for a bounded part **must** occupy Local Tier Standard.
