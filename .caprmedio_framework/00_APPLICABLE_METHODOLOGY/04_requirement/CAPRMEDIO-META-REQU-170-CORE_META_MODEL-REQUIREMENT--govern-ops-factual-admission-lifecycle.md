# Govern Ops factual admission lifecycle

An Ops Atom lifecycle represents factual admission rather than response handling: a draft is a governed Atom whose asserted fact is **not** yet admitted, an admitted factual record remains historical regardless of its operational response, **and** an invalidated, duplicated, **or** replaced record is archived.
