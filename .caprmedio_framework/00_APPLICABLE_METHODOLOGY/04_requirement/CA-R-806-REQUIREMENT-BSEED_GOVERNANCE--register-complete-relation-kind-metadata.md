# Register Complete Relation Kind Metadata

**every** admitted Relation Kind **must** have **`=1`** canonical metadata record that resolves its graph, declared direction, inverse direction, endpoint classes, cardinality, authority effect, transitivity, applicability, Status, **and** exclusive purpose.
