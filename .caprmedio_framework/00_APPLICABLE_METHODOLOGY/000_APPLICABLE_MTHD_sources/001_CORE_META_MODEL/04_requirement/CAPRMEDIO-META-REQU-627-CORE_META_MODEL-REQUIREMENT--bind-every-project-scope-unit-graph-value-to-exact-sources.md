# Bind every Project Scope Unit Graph value to exact sources

**every** Project Scope Unit Graph Projection value **must** bind to the exact Settings **or** Atom Revisions **and** digests, observed Scope Unit Directory Carriers, **and** Journal records used to derive it; an unavailable **or** contradictory authority source **must** produce an explicit unresolved result for the affected value **without** erasing independently observed structure **or** claiming complete source coverage.
