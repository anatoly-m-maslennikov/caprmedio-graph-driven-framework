# Admit implementation-independent Core rules

a reusable model rule belongs **in** CORE_META_MODEL **only** **when** it remains true as downstream languages, tools, hosts, providers, **and** repository layouts change, governs multiple layers **or** defines a boundary between layers, **and** can be stated **without** importing downstream implementation concepts.
