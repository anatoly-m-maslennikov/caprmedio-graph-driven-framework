# Register Scope Unit filename tokens

GOVERNANCE MUST register one stable filename token for every current Scope Unit:

| Scope Unit | Filename token |
| --- | --- |
| METAMODEL | `MMODEL` |
| SEMANTICS | `SEMNTC` |
| GOVERNANCE | `GOVERN` |
| CAPRMEDIO | `CAPRMEDIO` |
| FRAMEWORK_METHODOLOGY | `FR_MTHD` |
| FRAMEWORK_ENGINE | `FR_ENGN` |
| OPERATOR_DOCUMENTATION | `OPER_DOC` |
| CORE_EXTENSIONS | `CORE_EXTENSIONS` |
| RELEASES | `RELSS` |
| COMMUNITY_EXTENSIONS | `COMMUNITY_EXTENSIONS` |
| FIELD | `FIELD` |
