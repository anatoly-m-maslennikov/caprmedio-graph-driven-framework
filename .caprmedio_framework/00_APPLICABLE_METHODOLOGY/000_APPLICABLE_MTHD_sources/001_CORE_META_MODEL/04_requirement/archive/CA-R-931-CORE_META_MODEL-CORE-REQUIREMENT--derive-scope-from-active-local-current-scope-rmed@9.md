# Derive scope from active local current scope rmed

Scope of a Scope Unit **means** the derived set of **all** current Active Atoms owned by that Scope Unit whose Content Role is **in** (Requirement, Method, Evaluation, Delivery) **and** whose Claim Scope is bound **to** that current Scope Unit's Scope, independently of Local Tier; this set is defined **only** from a complete coherent authoritative frontier with ownership **and** Claim Scope bindings resolved independently of the derived set. a complete frontier with no qualifying Atoms defines an empty Scope; an incomplete **or** contradictory frontier **or** unresolved ownership **or** binding leaves the Scope result unresolved.
