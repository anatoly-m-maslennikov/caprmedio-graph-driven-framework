# Encode root Delivery directory names

EVERY root Delivery directory for a Scope Unit MUST match `<STRUCTURAL_LEVEL><OPERATOR_ORDER>_<UNIT_NAME>`, with one Structural Level digit followed by two Operator Order digits under the current default directory grammar.
