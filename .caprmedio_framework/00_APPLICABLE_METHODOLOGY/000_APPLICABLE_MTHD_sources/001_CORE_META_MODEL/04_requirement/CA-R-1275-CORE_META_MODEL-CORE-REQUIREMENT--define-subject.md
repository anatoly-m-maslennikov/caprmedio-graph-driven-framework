# Define Subject

a Subject **means** the Entity, Action, **or** Process referred **to** directly by an Atom through GOVERNS **or** DEPENDS_ON. being a Subject does **not** create another identity, make the target bearer-dependent on the Atom, **or** make a Term's wording **or** a particular execution interchangeable with that target.
