# Author Task Atoms

TO author one Task Atom, the Author MUST PERFORM ALL OF:

1. State exactly one Task Goal as the Claim.
2. Make the Task Summary express exactly the Task Goal.
3. State exactly one atomic or composite Task Scope.
4. State exactly one Definition of Done according to CA-M-123.
5. Include Task Details only when the information remains within the Task Scope and Task Goal and establishes no additional Definition of Done.
