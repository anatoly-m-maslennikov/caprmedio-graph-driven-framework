# Requirement — Use CARMADIO as the framework identity

The canonical framework name is **CARMADIO**. It expands to **Concern–Analysis–Requirement–Method–Assurance–Delivery–Implementation–Ops**, matching the eight governed Content roles.

The public outcome-oriented logline is **The Vibe-Code-to-Production Framework**. The name explains the framework's method; the logline explains its intended value.

Public documentation, project metadata, repository identity, package identity, installed methodology, and user-facing commands must converge on this canonical identity. Historical evidence may retain prior names and URLs when required for provenance.

## Primary claim

CARMADIO is the framework's canonical identity, expands to its eight Content roles, and uses The Vibe-Code-to-Production Framework as its public logline.

## Rationale

CARMADIO names the complete governed path from a concern through product definition, construction method, assurance, delivery, implementation, and real operation.
