# Define the Method Binding Type

`method_binding` is the relation-locus Method Type governing how one Method applies across explicit endpoints. It identifies the endpoints, exact Method revisions, applicability, parameters, compatibility rules, and permitted overrides without duplicating the endpoint Methods; endpoints may bind a project scope to an external Method or Profile or coordinate Methods owned by separate internal scopes.
