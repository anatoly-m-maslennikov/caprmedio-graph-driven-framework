# Define self-hosted Governance loci

In the CAPRMADIO framework repository, root framework sources and applied project artifacts are internal; the framework exposed through `.caprmadio/000_caprmadio_framework/` is external from the consuming project's context; artifacts whose primary meaning exists between explicit endpoints are relational. These loci describe meaning ownership rather than Git authorship, filesystem ownership, or byte identity.
