# Register Implementation Decision as a Method subtype

GOV registers `implementation_decision` as a direct subtype of the internal Method Atom Type. An Implementation Decision selects one bounded approach, structure, algorithm, dependency, protocol, or realization rule for implementing accepted specification without becoming the native Implementation, an execution Plan, a required outcome, an Assurance criterion, or a Delivery rule.
