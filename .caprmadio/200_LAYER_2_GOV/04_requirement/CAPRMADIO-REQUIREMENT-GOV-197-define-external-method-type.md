# Define the external Method Type

`external_method` is the external-locus Method Type for one Method or Method Profile contribution whose meaning is owned by an identified external source. It binds the exact source identity and revision without rewriting that meaning; contributions from a multi-role Extension retain their owning Content roles rather than being collapsed into Method.
