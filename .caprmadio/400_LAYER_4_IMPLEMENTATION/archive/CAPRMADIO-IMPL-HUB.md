# Applied IMPL artifacts

## Purpose

Own project-selected implementation-profile features and the immutable
artifacts that authorize their environment, code, Test, and Evaluation rules.

## Boundaries

Installed reusable profile definitions live under the installed methodology.
This applied layer records project selection, project-owned divergence, atomic
rationale, and current IMPL truth. TOOL remains the CAPRMADIO executable
contract; OPS remains post-implementation delivery and operation.

## Start here

- `01_concern` — open implementation-profile concerns.
- `03_requirement` — selected profiles and implementation requirements.
- `04_method` — technical implementation decisions.
- `05_assurance` — profile QA cases and assurance views.
