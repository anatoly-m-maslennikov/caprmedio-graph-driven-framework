# Requirement — Use CARMAIO as the framework identity

The canonical framework name is **CARMAIO**. It expands to **Concern–Analysis–Requirement–Method–Assurance–Implementation–Observation**, matching the seven governed Content roles and their operating loop.

The public outcome-oriented logline is **The Vibe-Code-to-Production Framework**. The name explains the framework's method; the logline explains its intended value.

Operation is not an eighth Content role. Operational governance remains expressible through the existing roles under an Ops layer or scope.

Public documentation, project metadata, repository identity, package identity, installed methodology, and user-facing commands must converge on this canonical identity. Historical evidence may retain prior names and URLs when required for provenance.

## Primary claim

CARMAIO is the framework's canonical identity, expands to its seven Content roles, and uses The Vibe-Code-to-Production Framework as its public logline.

## Rationale

The framework name should encode how the framework operates, while its logline communicates the outcome it provides. Keeping Ops as a scope rather than another Content role preserves the role model's semantic boundaries.
