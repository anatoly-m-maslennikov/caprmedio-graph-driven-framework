# Classify release and environment rules as Delivery

CAPRMADIO must classify normative rules for packaging, distribution, release, publication, promotion, target environments, environment topology, and runtime configuration sourcing as Delivery. Delivery states how a realized deliverable must reach and be made available to its users or target environments without claiming that the delivery has occurred.
