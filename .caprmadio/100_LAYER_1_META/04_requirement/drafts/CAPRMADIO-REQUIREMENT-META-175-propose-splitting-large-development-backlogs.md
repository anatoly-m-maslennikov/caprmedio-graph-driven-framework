# Propose splitting large Development Backlogs

CAPRMADIO must propose splitting a Development Backlog that exceeds fifty lines into one unscheduled Development Backlog and separate Version Plan files. CAPRMADIO must perform the split only after operator approval or an operator request at any file size, and the split must preserve the single-allocation invariant for every action point.
