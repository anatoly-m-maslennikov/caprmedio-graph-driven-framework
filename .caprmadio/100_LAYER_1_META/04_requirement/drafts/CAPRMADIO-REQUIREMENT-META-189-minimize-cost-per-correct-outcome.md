# Minimize cost per correct outcome

CAPRMADIO must minimize expected cost per correct governed outcome by using the least costly sufficient mechanism, preferring deterministic execution when the work is fully specifiable and reserving model reasoning for interpretation, judgment, or orchestration that cannot be safely reduced.
