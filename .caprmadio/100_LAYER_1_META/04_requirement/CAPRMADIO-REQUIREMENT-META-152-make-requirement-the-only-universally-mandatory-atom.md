# Requirement — Make Requirement the only universally mandatory Atom

Every governed development change that proceeds toward realization has at least
one Requirement Atom. Among the atomic roles in `CARMAD + O`, Requirement is the
only universally mandatory Atom. Concern, Analysis, Method, Assurance, Delivery,
and the future Ops Atom vocabulary are conditional on material need or an
applicable profile, risk rule, contract, or operator instruction. Ops Atom
semantics remain reserved until governed separately.

This baseline for `CARMAD + O` Atoms does not govern whether a short-lived Plan
Atom, Journal, or Projection is required. One Plan contains one or more action
points for one bounded execution package. Projections may be mandatory, but
they are generated from declared governed sources without operator-authored
projection content. Journals are required only by their applicable independent
rules.

Optional atomic occupancy never permits semantic misclassification. Whenever
CAPRMADIO persists atomic meaning owned by a Content role, it uses that canonical
role and its registered Type or subtype. A preserved rationale is therefore
always an Analysis Rationale Atom even though creating any rationale is
optional.

The canonical CAPRMADIO order defines semantic ownership and forward flow, not a requirement to create placeholder artifacts for every role.

## Primary claim

Requirement is the only universally mandatory Atom in `CARMAD + O`; mandatory
generated Projections and other non-atomic forms are governed independently.
