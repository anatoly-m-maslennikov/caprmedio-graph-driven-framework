# Change governed authority

For a proposed CPRMADI mutation:

1. Continue Exploration Mode.
2. Inspect applicable active Requirement atoms and their tiers.
3. Challenge the proposal against that authority.
4. Deepen Analysis or Concern when material ambiguity or conflict remains.
5. Present the exact add, update, or archive mutation.
6. Persist it only after explicit operator approval.

Create a draft only when the operator requests one.
