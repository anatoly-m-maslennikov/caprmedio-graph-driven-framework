# Upstream authority inventory

The singular Goal and the Principles for MECE, DRY, necessary complexity, falsifiable claims, explicit reliance boundaries, and outcome-driven improvement govern the engineering of CAPRMADIO and any future framework extracted from that work, so they belong to Upstream Layer minus one.

CAPRMADIO-specific behavior remains under PROJECT, including the graph operating model, the minimal default project model, operator-facing guidance, extensibility and configurability, substrate replacement, discipline independence, structural scaling, operator sovereignty, and the concrete six-Layer topology.

Existing PROJECT and downstream Core and Standard Atoms remain the direct specializations of the upstream Principles. Framework Engineering therefore has one Goal, multiple Principles, its own boundary Cores and Standards, and a directed descendant graph through PROJECT without becoming a seventh Project Layer.
