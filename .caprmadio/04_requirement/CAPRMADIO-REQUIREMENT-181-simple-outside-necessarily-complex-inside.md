# Simple outside; necessarily complex inside

CAPRMADIO keeps every operator-facing interface as simple as possible.
Complexity remains inside the engine only when necessary for correct behavior
and is exposed to the operator only when the current task requires it;
incidental complexity is removed rather than merely hidden.
