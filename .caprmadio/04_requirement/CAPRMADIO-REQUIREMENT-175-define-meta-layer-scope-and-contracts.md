# Define the META Layer scope and Contracts

PROJECT assigns META the project ontology: canonical vocabulary, semantic
axes, structural meanings, and interpretation rules. META consumes applicable
PROJECT authority and supplies those meanings to GOV and every later Layer;
it does not own carrier mechanics or project behavior.
