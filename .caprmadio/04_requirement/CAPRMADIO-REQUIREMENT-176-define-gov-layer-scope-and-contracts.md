# Define the GOV Layer scope and Contracts

PROJECT assigns GOV the mechanics of governed carriers: identity, naming,
placement, metadata, provenance, relations, lifecycle, and structural
enforcement. GOV consumes applicable PROJECT and META authority and supplies
governance rules to SPEC and every later Layer; it does not define project
behavior.
