# Define Ops layer scope and contracts

PROJECT assigns OPS post-delivery operation, supportability, runtime investigation, containment, recovery, and observation. OPS consumes applicable PROJECT, META, GOV, SPEC, IMPLEMENTATION, and DELIVERY authority; its findings may enter Exploration Mode but cannot create a backward authority edge.
