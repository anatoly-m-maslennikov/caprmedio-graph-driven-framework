# Define GOV layer scope and contracts

GOV is Layer 2 and owns governed-carrier mechanics: identity, naming, placement, frontmatter, provenance, relation encoding, lifecycle, catalogs, and structural validation. GOV consumes applicable PROJECT and META authority and supplies those mechanics to every later Layer; it does not define META meanings, project behavior, or realization.
