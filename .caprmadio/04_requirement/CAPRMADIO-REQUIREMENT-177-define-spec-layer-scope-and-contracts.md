# Define the SPEC Layer scope and Contracts

PROJECT assigns SPEC the applicable Requirement, Method, Assurance, and
Delivery authority that defines what and how the project must realize. SPEC
consumes applicable PROJECT, META, and GOV authority and supplies the normative
project specification to IMPLEMENTATION and every later Layer; it does not own
the realized artifacts.
