selected Project, persistent Plan, R/D targets, full current Method SourceRows
(`methods`; optional legacy `method_projection` is not required), applicable E
Atoms, source revisions and hashes, candidate, permissions, retry state, and
retained evidence. Missing, stale, conflicting, incomplete, or unauthorized
input returns `blocked`.

- Verify every current Method SourceRow and its source membership and
  freshness; inclusion does not make an unrelated Method or parent policy
  branch applicable.
- Validate applicable parent R/D/E/Method source rows independently against
  the authorized Project root and preserve separate independent policy
  branches in the obligation map.

  checks/review and evidence, or justified inapplicability; block missing coverage.

  each with dependencies, owner, and Definition of Done. Prepare tests before
  behavior and run the admitted runnable baseline.

  phase, then final checks after preliminary clearance, then final review.
  Complete only with current final review and checks on the same candidate;
  changed relevant bindings invalidate affected evidence without resetting budgets.
- Preserve authority, ownership, permissions, confidence, retry accounting,
  completed work, and retained evidence. Do not implement or route a later
  Step.
