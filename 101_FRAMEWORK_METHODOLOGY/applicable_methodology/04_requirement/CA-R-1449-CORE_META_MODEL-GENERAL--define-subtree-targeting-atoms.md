# Summary

Define Subtree-targeting Atoms

## Scope

the targeting of Atoms to a Scope Unit subtree.

## Claim

Subtree-targeting Atoms **means** the union of Targeting Atoms for the selected Scope Unit **and** **every** descendant Scope Unit.
