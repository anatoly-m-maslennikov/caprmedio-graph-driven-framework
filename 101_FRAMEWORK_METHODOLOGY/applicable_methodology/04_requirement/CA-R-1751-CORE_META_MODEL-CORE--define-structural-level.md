# Summary

Define Structural Level

## Scope

Scope Units and their Structural Levels.

## Claim

Structural Level **means** the signed ancestry depth of a Scope Unit relative **to** the Project Scope Unit at level **`0`**, with positive levels inside the Project **and** negative levels **only** for explicitly admitted Bootstrap Scope Units outside that Project.
