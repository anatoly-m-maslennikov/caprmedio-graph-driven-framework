# Summary

Define Entity/Continuant/Object/Governing Configuration

## Scope

authoritative non-Atom configuration.

## Claim

Governing Configuration **means** authoritative non-Atom content that supplies declared structural facts or selected configuration values for a Project. it is **not** a derived Projection.

## Details

Candidate #5 retains Governing Configuration while placing Settings and Structure under Project properties; Candidate #6 retains that distinction. CA-R-1402, CA-R-1738 and CA-R-1483 define specific configurations, not this general kind. No selected Settings values are copied into this draft.
