# Summary

Define Entity/Continuant/Object

## Scope

Objects in the Entity model.

## Claim

an Object **means** a Continuant representing what is governed or described, rather than who acts.

## Details

Candidate #6 retains Object separately from Actor, History, Projection, Selection and Term. Atom, Governing Configuration, Scope Unit and Relation are examples from its agreed backbone, not a closed list imposed by this draft. CA-R-1248 defines Entity and CA-R-1191 defines Primary Entity; neither defines this Object branch. The old Artifact / Structural Entity partition remains separate content-migration work.
