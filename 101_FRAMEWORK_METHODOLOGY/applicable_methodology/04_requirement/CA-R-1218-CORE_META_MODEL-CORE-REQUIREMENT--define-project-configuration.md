# Summary

Define Project Configuration

## Scope

Project-owned Methodology Source authority that expands the Core Meta-Model.

## Claim

Project Configuration **means** Project-owned Methodology Source authority that expands the Core Meta-Model with Project-specific rules, constraints, **and** defaults **without** replacing CORE_META_MODEL authority at **any** Local Tier **or** duplicating current values owned by Settings Artifacts.
