# Summary

Permit Version preservation for carrier-only relocation

## Scope

carrier-only relocation of an Atom Carrier.

## Claim

a carrier-only move, rename, recoding, **or** lossless Entity-name change of an Atom Carrier **must** retain the current Version **when** it preserves governed meaning, Atom identity, Claim, Claim Scope, Atom Scope, **and** authored direct semantic relations under CA-D-304; a same-ID meaning change **must** create a new Revision under CA-R-1371.
