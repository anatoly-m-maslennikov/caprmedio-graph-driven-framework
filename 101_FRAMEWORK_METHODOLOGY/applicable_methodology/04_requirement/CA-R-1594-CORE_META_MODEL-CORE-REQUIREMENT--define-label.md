# Summary

Define Label

## Scope

Labels.

## Claim

a Label **means** an Operator-controlled, mutable word **or** phrase used as a Property of an Entity **to** aid navigation **and** understanding, **without** determining that Entity's identity, Type, Subtype, structure, authority, **or** behavior.
