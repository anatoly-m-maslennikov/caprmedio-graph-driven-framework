# Register the GRAPH_APP unit

## Applicable when

Use this Method when registering or changing the GRAPH_APP Scope Unit owned immediately by APPS.

## Procedure

1. Resolve the active APPS authority and the current immediate-child Scope Unit declarations.
2. Register exactly one unordered immediate child with prefix `GRAPH_APP`, Structural level `4`, address `002_FRAMEWORK_ENGINE/PROGRAMMATIC/APPS/GRAPH_APP`, and the corresponding source path.
3. Assign GRAPH_APP ownership of the source indexer, a rebuildable database derived from governed Atoms and Journals, a local read-only server, and interconnected web pages.
4. State that those read models and views are derived support and do not become project authority.
5. Confirm that the declaration has one immediate typed owner, one identity, and no conflicting owner or responsibility claim.

## Outcome

GRAPH_APP is one identifiable immediate APPS unit with the required boundary, address, realization path, and non-authoritative graph-serving responsibilities.

## Failure or stop

Stop when GRAPH_APP is missing, duplicated, non-immediate, ordered, assigned a conflicting address or path, or given project authority.
