# Provide a separated local App Runtime

Deliver the local App with explicit carriers for source indexing, derived database state, backend services, frontend assets, and transient interface state. Expose versioned typed service contracts between frontend and backend, route governed mutations only through admitted Doers, and keep rebuildable databases, caches, logs, locks, and session state in `.caprmedio_runtime`.

Provide supervised startup, shutdown, restart, timeout, cancellation, and recovery behavior for background work. Render project content as data, expose understandable status and failures, and make primary workflows keyboard-operable.

Candidate alignment: CA-D-001, CA-D-002, CA-D-003, CA-R-819, CA-R-827, CA-R-861.
