# Define the APPS Feature scope

`APPS` with filename token `APPS` is one unordered Feature Scope Unit owned immediately by `PROGRAMMATIC` at Structural level `3`. It owns CAPRMEDIO operator-facing application products and agent-host plugin packages through exactly two immediate unordered Feature Scope Units: `GRAPH_APP` and `AGENT_HOST_PLUGINS`.
