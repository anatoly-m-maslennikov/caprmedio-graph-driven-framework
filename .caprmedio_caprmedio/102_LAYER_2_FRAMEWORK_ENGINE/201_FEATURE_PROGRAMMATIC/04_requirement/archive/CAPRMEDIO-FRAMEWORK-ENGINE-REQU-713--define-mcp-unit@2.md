# Define the MCP Feature scope

`MCP` with filename token `MCP` is one unordered Feature Scope Unit owned immediately by `PROGRAMMATIC` at Structural level `3`. It owns the provider-neutral Model Context Protocol discovery, schema, and dispatch interface that projects active CAPRMEDIO Tools for agent use without owning Tool behavior, Skill procedures, application behavior, or agent-host-specific packaging.
