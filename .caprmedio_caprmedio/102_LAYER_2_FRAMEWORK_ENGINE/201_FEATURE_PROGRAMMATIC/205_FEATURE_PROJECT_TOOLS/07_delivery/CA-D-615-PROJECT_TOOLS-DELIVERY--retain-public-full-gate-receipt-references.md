# Summary

Retain public Full Gate receipt references

## Scope

the fresh Public Full Gate evidence for one public release.

## Claim

public-release gate evidence **must** retain one fresh typed Public Full Gate receipt for the stable selected candidate and initial public-material closure before its first public effect. The exact later PR-URL/concise-Version-History metadata follow-up reopens that public gate after proving the candidate and all non-metadata bindings unchanged.

## Details

This Delivery does not copy, synthesize, or replace `RELEASE_VERSION` evidence carriers. The Tool derives the candidate and package identity locally from the reread Source Proof and verified typed local Full Gate result, then records actual reports from the fresh public suite; it accepts no caller-supplied receipt, package identity, pass result, or digest. The evidence root and receipt reference are safe Project-relative recorded carriers, and every SHA-256 is lowercase 64-hexadecimal.

The retained Public Full Gate remains bound to the exact D566 candidate snapshot, framework version, `version.toml` digest, package identity, initial public-material closure, complete public-suite evidence, local promotion, and live verification. A changed executable candidate, Methodology, package, Version, `version.toml`, or initial public-material closure cannot reuse it. Only an actual PR URL and concise Version History metadata transition proved to be otherwise unchanged may reopen it.
