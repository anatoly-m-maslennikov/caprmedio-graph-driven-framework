# Register immediate executable Tool folders

**every** immediate canonical folder under `102_FRAMEWORK_ENGINE/201_PROGRAMMATIC/301_TOOLS/` that owns one independently executable deterministic Tool entrypoint **must** correspond one-to-one **to** an immediate `unordered_unit` Tool Scope Unit owned by `TOOLS`. the Tool is active by default **and** **may** be excluded from the active Tool frontier **only** by explicit current Project authority **or** Configuration. shared libraries, caches, tests, **and** migration collections that do **not** own one canonical independently executable Tool entrypoint **must not** become Tool Scope Units.
