# Extract an Extension candidate from Project Adaptation

The framework must provide one deterministic Tool that accepts operator-selected Project Adaptation Atoms, resolves their required dependency closure, and produces a separately identified Extension candidate with exact source references or fails without silently omitting unresolved authority.
