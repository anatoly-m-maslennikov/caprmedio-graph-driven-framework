# Describe one admitted Atom replacement

## Claim checked

the replacement Method describes one admitted atom replacement **before** it is applied.

## Test case

Submit one replacement request with an admitted source, successor, **and** stated change class.

## Acceptance criteria

the description preserves the source identity **and** exact successor boundary **without** applying, promoting, **or** archiving either carrier.

## Failure disposition

Reject the request **when** the replacement boundary **or** admission evidence is incomplete.
