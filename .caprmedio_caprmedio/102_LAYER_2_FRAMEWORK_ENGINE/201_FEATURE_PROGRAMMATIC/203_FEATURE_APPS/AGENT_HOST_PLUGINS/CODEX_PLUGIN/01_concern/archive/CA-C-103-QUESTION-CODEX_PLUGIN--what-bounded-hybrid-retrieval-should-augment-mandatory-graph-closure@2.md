# What bounded hybrid retrieval should augment mandatory graph closure?

This Concern is derived from CA-A-060 and concerns the context-routing
boundaries in CA-R-1104 and CA-M-199.

WHAT optional lexical, graph-neighborhood, temporal, or semantic retrieval
mechanism, if any, should augment deterministic authority closure for Codex
context while preserving complete mandatory authority, project isolation,
provenance, freshness, and reproducibility?
