# Rebuild one as-is Implementation Inventory

## Claim checked

The Implementation Inventory records the selected observed native frontier without inventing authority or structural interpretation.

## Test case

Build the Inventory twice from one sealed native frontier containing directories, files, modules, and declared dependencies.

## Acceptance criteria

Both outputs represent the same observed carriers and relations reproducibly and contain no governed structural or feature claims.

## Failure disposition

Reject the Inventory as stale, interpretive, or non-reproducible.
