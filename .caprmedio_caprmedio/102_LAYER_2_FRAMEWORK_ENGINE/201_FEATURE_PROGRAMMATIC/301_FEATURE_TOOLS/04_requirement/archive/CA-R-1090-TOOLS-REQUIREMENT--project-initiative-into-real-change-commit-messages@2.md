# Project Initiative into real-change commit messages

Every real-change Git commit message MUST begin with the sealed Initiative's short human-input summary before the first ` | `. The remaining fields MUST identify the governed change class and affected carrier without using a process, thread, adapter, queue, or relation-list value as the Initiative projection:

```text
<initiative-summary> | <CHANGES> | <affected-carrier>
```

The short summary is a deterministic bounded Projection for Git navigation, not the Initiative authority. The complete structured Initiative remains in durable action state and the canonical Journal event. Journal-only batch commits MUST use a distinct deterministic batch message and MUST NOT impersonate a real-change Initiative commit.
