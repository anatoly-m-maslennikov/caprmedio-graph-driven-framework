# Register immediate executable Tool folders

Every immediate canonical folder under `002_FRAMEWORK_ENGINE/PROGRAMMATIC/TOOLS/` that owns one independently executable deterministic Tool entrypoint MUST correspond one-to-one to an immediate `unordered_unit` Tool Scope Unit owned by `TOOLS`. The Tool is active by default and may be excluded from the active Tool frontier only by explicit current project authority or Configuration. Shared libraries, caches, tests, and migration collections that do not own one canonical independently executable Tool entrypoint MUST NOT become Tool Scope Units.
