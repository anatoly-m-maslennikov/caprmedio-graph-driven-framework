# Summary

Clarify Plan bundle history relocation

## Concern

When archiving a Plan, may its matching Directory Carrier carry retained historical subtrees byte-for-byte unchanged as part of that current bundle move, or must those historical paths remain in place? Current child Atoms still require independent Actions; new Archived Plan Markdown files remain flat in shared 03_plan/archived in either case.

## Evidences

D461@15/E502@13 preserve exact older bytes, Version and Status and do not authorize legacy-tree migration; they do not explicitly make old paths immutable during an otherwise authorized whole matching-directory move. O029@8 admits matching-directory relocation but its blanket retained current-Plan hierarchy is superseded by Core flat placement. Read-only adjudication initially inferred path immutability, then withdrew it after exact source challenge: confidence is 89 percent for that narrow history-location boundary, below the Operator 95 percent threshold. No new refusal gate is admitted.

A single Operator question has been sent. P2484 settled path resolution and source-bound validator/test preparation may continue independently. P2485 history-bearing bundle behavior and P2489 corresponding final wording wait for the answer. No live carrier migration, history rewrite, release, deployment or historical Run replay is authorized.

## Blast radius

Only the retained-history subtree placement within an explicitly archived current Plan bundle. The question does not reopen flat new Archived Plan placement, older-byte preservation, separate descendant Actions, non-Archived hierarchy or Stage 2 Scope Unit deferral.

## Resolution

The Operator answered the container question and rejected optional descendant modes. Archive always includes recursively contained latest Atoms; when the requested parent Status is Done, contained latest Plans already Done remain unchanged and all other contained latest Plans become Canceled. Archive has no Done-child exception. Retained-history subtrees may accompany the matching Directory Carrier byte-for-byte without rewriting older Version, Status, Updated At or content. Older Revisions are not independent Status targets; newly Archived Plan files remain flat. This resolves the bounded history-location ambiguity, not implementation acceptance. R1521/D461/E502 and O029/E306 are being reconciled before P2485/P2494 execution; no live migration or held-batch replay follows.
