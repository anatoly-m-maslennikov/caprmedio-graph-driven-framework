## Summary

PROMPTS owns agent and Operator prompt implementations while existing owners retain their authority

## Claim

PROMPTS **must** own prompt-based implementations that are used by an AI Agent **or** presented to the Operator. The existing owners retain ownership of **all** of the following:

- the implemented Methodology Action.
- the implemented Workflow.
- decision authority.
- programmatic mechanics.
