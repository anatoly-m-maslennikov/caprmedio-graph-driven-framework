# Provide thin portable Skill packages

Deliver each Skill as a portable package with discovery metadata, a bounded instruction body, and only the scripts, references, templates, or assets required by its procedures. Keep full Methodology authority and software contracts in their canonical Engine places and refer to them instead of copying them into Skill prose.

Encode every delegation with its target, input, authority boundary, expected result, and stop or escalation condition. Preserve progressive disclosure so hosts can discover the Skill cheaply and load detailed context only when the active procedure requires it.

Candidate alignment: CA-D-001, CA-D-002, CA-M-002, CA-M-003, CA-M-005, CA-M-006, CA-R-861.
