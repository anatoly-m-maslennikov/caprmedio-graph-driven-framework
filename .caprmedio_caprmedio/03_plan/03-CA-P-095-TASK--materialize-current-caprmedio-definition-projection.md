# Materialize the current CAPRMEDIO Definition projection

WHEN the current Principle set is accepted, THE Assignee MUST materialize one
current CAPRMEDIO Definition as a generated compact projection of those
Principles and synchronize the README's framework identity with it.

## Scope

The current external Goal, the current active Principle Atoms, the canonical
above-Project Definition location selected by current BSEED authority, and the
README paragraphs that state what CAPRMEDIO is.

## Definition of Done

THE Task is NOT DONE IF (the Definition is authored as an independent source of
truth OR its exact Principle source identities and revisions are absent OR it
does not identify CAPRMEDIO compactly as an Intelligent Work Environment
framework OR it repeats the Goal as the Definition OR the README contradicts
the generated Definition OR Principle changes can leave the Definition current
without regeneration OR current BSEED authority does not accept the carrier's
location and Projection shape).

## Details

Keep the Goal separate and upstream. Compile only current accepted Principles,
preserve their equal authority, and keep the Definition shorter than the
Principle set. The README may expose the Definition in simple language, but it
must not become a second manually maintained Principle catalog.
