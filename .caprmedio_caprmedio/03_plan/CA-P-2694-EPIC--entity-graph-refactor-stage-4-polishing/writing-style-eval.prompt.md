# Writing style eval

Check the supplied text against the supplied Writing Style Guide. Use that guide as the rule source; do not add your own style rules.

Check all five areas:

1. Syntax
2. Vocabulary
3. Structure
4. Formatting
5. Content

Use the supplied purpose, audience, source facts, defined names and required format. Check whether the wording keeps the intended meaning.

Review only CCE and text writing. Do not assess business rules, Workflow design, the entity model, tools or implementation.

- Report real issues, not changes based only on personal preference.
- Compare with the supplied source. Flag unnecessary changes to clear, correct wording or structure; suggest keeping the source. Allow changes required by explicit instructions.
- Do not reject a needed technical term, an established name, or a short Summary just because it is not a full sentence.
- Do not paraphrase familiar principles such as DRY or MECE.
- Do not flag repetition that a required section or clear reference needs.
- Suggest the smallest fix that meets the guide and keeps the meaning.
- If context is missing, name what cannot be checked. Do not guess.
- Do not rewrite the whole text unless asked.
- For a Summary, flag an abstract or a detailed retelling used instead of a short, meaningful title.

Return:

Result: Pass / Needs changes / Needs context

For each issue:
- Area
- Exact quote
- Problem
- Smallest fix

If there are no issues, return “Pass” without filler. Do not add a score or a word limit unless requested.
