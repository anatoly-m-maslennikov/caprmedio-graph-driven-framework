# Writing Atom content

Use the [role-specific one-shot writers](content-role-prompts/README.md) for C, P, R, M, E, D and O. Summary is part of the content; each writer returns the complete Markdown after an internal check.

A is an exception: choose a report structure for its purpose and Type instead of forcing a universal short template.

When review is useful, use [Review Atom content](atom-content.eval.prompt.md) with the source, output and selected role prompt. Correct findings with the same writer. No separate Summary or fix prompt is needed.

The earlier [generic writer](atom-content.prompt.md) and its [twelve-case experiment](unified-content-prompt-test.md) remain as development history. Their scores are not evidence for the new role-specific prompts.
