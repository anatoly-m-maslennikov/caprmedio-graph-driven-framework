# Writing style guide

Write or edit the supplied text in simple English. Keep its meaning. Correct spelling and grammar.

Keep the source wording and structure when they are already clear and correct. Change only what is needed to follow this guide or an explicit instruction.

Use the supplied facts, purpose, audience, defined names and required format.

## Syntax

- Use short, direct sentences.
- Split a dense sentence when that makes it clearer.
- Make references and conditions clear.
- Do not force a fixed opening or sentence form.

## Vocabulary

- Prefer simple, familiar words.
- Use complex or technical words only when needed.
- Keep defined names and established terms. Do not rename them for variety.
- Keep familiar principle names, such as DRY and MECE. Do not replace them with long descriptions.

## Structure

- Put the main point first.
- Group related points. Keep each condition close to the point it limits.
- Write a shared opening once, then list its points.
- Use numbered lists only when order matters.
- A short text can stay a short paragraph.

## Formatting

- Keep formatting simple and consistent.
- Follow the required headings and template, when supplied.
- Use headings for useful groups, bullets for lists, and code blocks for code or formal expressions.
- Keep names, IDs, code and formal notation exact. Preserve required case.

## Content

- Use the supplied facts and instructions. Do not invent facts, rules or requirements.
- Keep who does what, conditions, limits and the difference between must/may and all/any.
- Include enough context to make the meaning clear.
- Avoid needless repetition. Repeat a point when a required section or a clear reference needs it.
- A Summary must carry the meaning. A familiar name or short instruction can be a Summary. It need not be a full sentence.
- For Atom content, follow its supplied section template. Keep supporting details within the Claim.

If missing information would change the meaning, ask one short question instead of guessing.

Return the finished text. Explain changes only when asked.
