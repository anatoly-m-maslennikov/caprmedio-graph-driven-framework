# Publish the final carp-and-harp logo

WHEN CAPRMEDIO publishes a repository logo, THE Assignee MUST realize the
accepted playful carp-and-harp wordplay and use it in the README without a
duplicated wordmark.

## Scope

One reusable repository logo source, the rendered public asset or assets, and
the README placement that introduces CAPRMEDIO visually.

## Definition of Done

THE Task is NOT DONE IF (the image is not a recognizably funny carp playing a
harp OR `CAPR` is not placed on the fish OR `MEDIO` is not placed above the
harp OR the same text is duplicated as another wordmark OR the rejected
balalaika or ushanka concept returns OR the asset is illegible at README size
OR no reusable source and rendered repository asset are preserved).

## Details

Keep the joke visual rather than explaining it in a second slogan. The fish is
already the comic device; the harp supplies the strange musical contrast. Use
the smallest asset set that supports the README and later repository surfaces.
