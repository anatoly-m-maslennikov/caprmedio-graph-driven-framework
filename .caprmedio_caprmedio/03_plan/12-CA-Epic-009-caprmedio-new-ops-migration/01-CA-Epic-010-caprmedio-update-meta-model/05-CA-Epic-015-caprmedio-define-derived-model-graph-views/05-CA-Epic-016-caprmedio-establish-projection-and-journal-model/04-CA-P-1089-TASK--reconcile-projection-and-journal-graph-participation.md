# Reconcile Projection and Journal graph participation

the Assignee **must** reconcile graph participation **and** Relation Kind ownership for Projections **and** Journals.

## Scope

(the selected generic Projection **and** Journal graph-participation authority, including its use of graph-qualified Relation Kinds). the source admission boundary is selected active RMEDO authority **in** CORE_META_MODEL at `.caprmedio_framework/00_APPLICABLE_METHODOLOGY/000_APPLICABLE_MTHD_sources/001_CORE_META_MODEL`, reconstructed from CA-P-976 **and** the ordered accepted source maps, including the sealed CA-P-980 direct-Subjects stage. Project Principles are read-only governing prerequisites. Drafts, prior archives, completed Task records, sealed evidence, generated Applicable Methodology, settings values, Tool Implementation, **and** unrelated CAP Atoms are excluded from mutation. administrative Task records, exact prior revisions, **and** append-only Journal evidence are recorded separately.

## Definition of Done

the Task is **not** Done **if** (Entity kind, graph membership, **and** authority are conflated **or** a shared node gains a second identity merely by appearing **in** another graph **or** a required Relation Kind lacks its owning graph kind **or** an internal graph relation is confused with a relation connecting its Projection **or** Journal Artifact **to** another node **or** a derived reverse edge becomes independently maintained authority).

## Details

reuse CA-R-1246: a graph kind owns its Relation Kinds; its graph instances reuse those definitions. a Projection **or** Journal is also an Artifact **and** **may** be a node **in** a graph, while a graph Projection represents other nodes **and** edges. keep those levels distinct. preserve graph-qualified relation identity, direction, endpoints, applicability, cardinality, **and** source provenance; compatible names **or** endpoints do **not** permit cross-graph substitution. preserve the existing Entity identity when multiple graphs represent it. use the current registry before adding a Relation Kind; add **only** a demonstrably missing relation within this scope **and** ask the Operator **if** confidence about its exact signature is below the effective Autonomous Confidence Threshold. do **not** invent a graph kind for **every** view **or** a universal relation vocabulary. direct Subject navigation remains with CA-P-1082, combined navigation with CA-P-1083, **and** Operation control flow with CA-P-980.

reuse accepted authority **and** preserve one Claim **and** one Claim Scope Unit per Atom. R establishes the model, M covers Implementation choices **or** conventions, E checks correctness, D specifies Carriers, **and** reusable Actions **or** Processes belong **to** O. do **not** require an Atom **in** **every** Content Role. do **not** settle the unapproved per-Entity R/D/M/E counts **or** invent Entities merely **to** satisfy a count.
