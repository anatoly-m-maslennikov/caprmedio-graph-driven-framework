# Select priority-governed alternatives

For an affected scope and project stage, first derive the one effective
Operator priority order required by CA-R-860. Reject every alternative that
violates a non-negotiable constraint. Then apply each active, applicable
operator-priority criterion in that order; the current criterion set includes
CA-M-093 through CA-M-100 but remains extensible.

Choose the alternative that is strictly preferred at the first criterion where
admissible alternatives differ. When the order is incomplete, two alternatives
remain tied after all applicable criteria, or criteria are incomparable, report
the alternatives, constraints, evidence, and unresolved comparison to the
Operator. Do not break a tie or infer a preference automatically.
