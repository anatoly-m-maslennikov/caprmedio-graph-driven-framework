# Preserve canonical meanings through mappings

Treat a mapping as admissible only when it preserves every canonical
distinction declared as required for its intended scope. A mapping may instead
use a narrower scope, specialization, or loss only when the Operator accepts
that exact boundary and its consequences. When neither preservation nor an
accepted boundary can be demonstrated, stop the affected adaptation and return
it to the Operator; do not infer a universal equivalence threshold.
