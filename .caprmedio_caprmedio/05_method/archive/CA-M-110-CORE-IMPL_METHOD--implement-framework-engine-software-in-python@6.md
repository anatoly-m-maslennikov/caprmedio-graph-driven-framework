# Implement FRAMEWORK_ENGINE software in Python

Implement applicable CAPRMEDIO FRAMEWORK_ENGINE software—Tools, App backend
services, and MCP components—in Python under the technical contract in
`pyproject.toml`, table `tool.caprmedio.framework_engine_software`. Use the
standard library before admitting a dependency when both provide the required
behavior with comparable clarity and reliability. For a dependency or
non-Python exception, record its required capability or native-interface need,
bounded carriers, integration contract, added boundary cost, supporting
evidence, and Operator acceptance at the contract's declared Delivery and
Evaluation locations.

This Method applies only to the Software implementation group; it does not
create a Scope Unit and does not govern Skills. It selects a realization
language rather than making Python part of CAPRMEDIO's discipline-independent
governed meaning. A future replacement remains possible through replaceable
realization.
