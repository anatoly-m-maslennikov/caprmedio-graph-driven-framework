# Apply lexicographic selection when selected

**to** select among alternatives **when** the Operator has selected a lexicographic priority model for the affected Scope **and** Project stage, first resolve that model under CA-R-860 **and** its effective criterion order. reject **every** alternative that violates a non-negotiable constraint. **then** apply **every** active, applicable Operator-priority criterion **in** that order; the current criterion set includes CA-M-093 through CA-M-100 but remains extensible.

choose the alternative that is strictly preferred at the first criterion **where** admissible alternatives differ. **when** the order is incomplete, alternatives remain tied **after** **all** applicable criteria, **or** criteria are incomparable, report the alternatives, constraints, evidence, **and** unresolved comparison **to** the Operator. do **not** break a tie **or** infer a preference automatically. this Method **must not** replace a different Operator-selected priority model with lexicographic selection.
