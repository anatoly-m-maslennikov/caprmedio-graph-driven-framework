## Summary

Trial global Object, Carrier and Graph Syntax Definitions with scoped Aspects

## Proposal

Each Object (Continuant or Occurrent), Carrier and Graph Syntax entity has one dedicated global R/Entity Definition, with an exact governed entity. An Object remains the same Object across Scope Units. Local Rs may add applicable constraints; they are not competing Definitions. The accepted Relation Definition template remains eligible without introducing a subtype hierarchy.

Aspect definitions use a looser rule and may differ by Scope Unit or explicit applicability scope. Do not force a separate Definition for every shared Aspect topic or characteristic. Additional Rs may add coherent requirements while one Atom still has one Claim. Report where the dedicated-Definition trial adds redundancy or fits badly.

The Operator confirmed all 133 shared/formal starting cases. The initial 337 parsed paths split into 280 strict and 57 Aspect paths. Normalize equivalent property spelling to one logical identity. Keep the Epic Active; review the full combined cohort for coherence, then fix findings and rebuild.

## Status

Accepted for the current trial. This supersedes the blanket exact-one rule for Aspects. Subtype restructuring and Engine implementation remain deferred.
