# The operating graph includes realized project nodes

The graph is the complete operating model because Implementation, Delivery, and Ops artifacts representing code, deployments, executions, and operational facts are nodes in the same graph as governed authority. Narrowing the Principle to normative authority would create a false boundary between the project model and its realized state; therefore, neither a replacement Principle nor a separate graph-versus-reality Core is required.
