# Summary

Consolidate the closed-corpus candidate register

## Question

Which completed saved harvest outputs supply distinct reusable propositions, how do their repeated candidate/refinement forms coalesce, and what bounded reconciliation remains?

## Scope

Saved evidence only. The 114 Done Plans in the now-canceled P1118 tree resolve to 102 completed harvest Analysis reports, three metadata-only Analysis reports and nine additional preflight/metadata/save-control Plans. The 12 administrative Plans therefore do not inflate the 102 harvest-packet count. A1043 remains excluded as partial. Epic1117 v2's 5,463 record count is inherited, not reharvested or independently recounted. No session file or session index text was opened. No Operation, RMED, code, settings, service, Git or Journal was changed. Other agents own shared controls and first-five reconciliation outcomes.

## Approach

Fully read P1345 and current closed-corpus Epic1117/P1119, and all five bound reconciliation Plans. Reopened live Goal13 and verified unchanged fingerprints for all14 previously fully read active Project Principles. Follow Done Plan → own Analysis provenance through analysis_for, is_result_of, analyses or the first relates_to Plan; this is provenance admission, not semantic acceptance of historical reports. The source tree's relocation is preserved.

Extract saved candidate/refinement sections and named JSON candidate groups without interpreting embedded raw evidence. Preserve exact report/section/ordinal or JSON-fence/key/index references and owning Done Plan. Four differently headed reports retain report-level candidate/refinement locators explicitly. Original saved candidate texts remain in their source Analysis, not copied into this register. Each entry has one primary family plus optional cross-family links; compound intents and source-specific refinements remain accessible through exact source locators.29 repeated named Markdown/JSON forms are represented by earlier entries, with both references retained. Exact first-five assignments are narrow and do not imply those entire families are reconciled.
