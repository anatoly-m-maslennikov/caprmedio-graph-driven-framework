# Operator judgment gates costly improvement

Continuous improvement consumes scarce context tokens, model spend, and operator time. Its cost becomes worthwhile when recurring corrections make project work uncomfortably slow enough that the operator chooses to sharpen the framework instead of continuing with the current process. Observed friction and deliberate analysis inform that judgment, but only the operator decides when to spend the required time and money.
