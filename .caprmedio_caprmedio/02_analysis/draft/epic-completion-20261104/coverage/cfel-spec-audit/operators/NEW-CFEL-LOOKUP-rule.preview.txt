## Summary

Resolve nearest compatible Property value with LOOKUP

## Claim

### Formal Claim

```CFEL
# model
p ?== LOOKUP(R, q)
```

### Prose Claim

`LOOKUP(R, q)` is a contextual fallback expression. Starting at the bearer of target Property `p`, follow one existing outgoing link of declared Relation `R` at each step, in R's declared direction. Exclude the starting bearer. Return the nearest authored value of `q` that is applicable to that bearer. Resolve `q` by full Property declaration identity and effective MODEL applicability; skip only an inapplicable Property or an absent authored occurrence. At a known end with no applicable authored value, return absence so the next `?==` branch may be considered. Do not match by bare name or invent a Property slot.

A present invalid value, unresolved applicability or graph fact, multiple outgoing targets, or revisiting a bearer is an error. This rule grants no Relation permission and does not change Relation direction. `LOOKUP` does not itself write a Carrier or file.
