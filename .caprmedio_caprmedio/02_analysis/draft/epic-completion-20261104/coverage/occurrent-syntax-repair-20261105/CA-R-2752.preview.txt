## Summary

Declare Action Run

## Claim

### Formal Claim

```CFEL
# model
Action Run ((NARROWER_THAN)) Execution;

# instances
$run[<Action Run>] {::1}((IS_EXECUTION_OF)) $definition[<Action>];

$action_run[<Action Run>] {::0+}((IS_CONTAINED_BY)) $step_run[<Step Run>]
```

### Prose Claim

An Action Run launched by a Step Run is contained by that Step Run.

## Semantics

An Action Run is an actual execution of one Action.
