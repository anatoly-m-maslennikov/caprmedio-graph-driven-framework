## Summary

Define RECORDS Relation

## Claim

### Formal Claim

```CFEL
# model
$relation[<Relation>, (.Name = RECORDS)];

$inverse1[<Relation>, (.Name = IS_RECORDED_BY)];

$relation ((HAS_INVERSE)) $inverse1;

$relation ((HAS_CLASSIFICATION)) Derivation == Direct;

# instances
$event_record[<Event Record>]((RECORDS)) $event[<Event>]
```

## Semantics

RECORDS is the stored Relation from an Event Record to the Event it describes. Its declared inverse IS_RECORDED_BY is a derived view; an Event Record is distinct from the Event.
