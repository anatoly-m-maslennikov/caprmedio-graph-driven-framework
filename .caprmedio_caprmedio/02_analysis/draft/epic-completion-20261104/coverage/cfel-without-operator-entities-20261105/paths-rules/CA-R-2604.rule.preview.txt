## Summary

Bind selected instances

## Claim

### Prose Claim

`<Kind>` references a declared Model kind. `$x[<Kind>, (conditions)]` binds an existing instance as a named participant, with grouped conditions evaluated against that participant. `$<Kind>` selects anonymously. Repeated anonymous selections use the same domain but do not assert their referents identical or different; use a named participant to express the same selected identity. Selection creates no instance and does not turn a model entity into a data-layer fact. `$<Journal>{::1}` and `$journal[<Journal>]{::1}` each constrain the selected logical Journal instance population within the Current Project to exactly one. A variable introduced by a standalone typed instance selector remains in scope for following statements in the same CFEL fenced block. A variable introduced in an IF condition is in scope within that condition and its matching THEN group only; it is not in scope in following statements. A new IF binding uses a different name from an already bound outer variable; references to that outer variable retain its identity.
