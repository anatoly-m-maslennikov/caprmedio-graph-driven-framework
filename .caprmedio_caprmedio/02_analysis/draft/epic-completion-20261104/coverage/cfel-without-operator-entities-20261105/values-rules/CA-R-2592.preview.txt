## Summary

Define CFEL allowed-value syntax ::

## Claim

### Prose Claim

`::` admits an allowed value in a Formal Claim; `{::n}` specifies the allowed count of a qualified selection. Neither form is assignment or an `IS_ALLOWED_VALUE_OF` Relation.
