## Summary

Define Property-value selection with `:=`

## Claim

### Prose Claim

In a Subject or filtered Node expression in a Formal Claim, `:=` combines an admitted Property value with selection, as in `Workflow/(.Purpose := Runtime)`. It is selection syntax, not assignment.
