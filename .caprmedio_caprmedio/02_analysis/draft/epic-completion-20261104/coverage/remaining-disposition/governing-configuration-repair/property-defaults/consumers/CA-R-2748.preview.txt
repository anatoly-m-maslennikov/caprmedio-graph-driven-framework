## Summary

Unify Operator-selected Project Settings

## Claim

### Prose Claim

Project.Settings owns the Operator-selected Project initialization inputs and applicable CAPRMEDIO behavior and configuration choices. Each selected setting has one authoritative owner in its Project. Atoms define permitted parameters, constraints, applicability, and applicable Property defaults without duplicating selected values or defaults.
