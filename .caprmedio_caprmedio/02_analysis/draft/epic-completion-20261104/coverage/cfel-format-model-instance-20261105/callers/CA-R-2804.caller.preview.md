## Summary

Bind selected instances

## Claim

### Prose Claim

`[Format]` constrains values and `<Model>` denotes a Model reference. `$x[<Model>, (conditions)]` binds existing instances whose `INSTANCE_OF` Relation targets that Model within a declared Relation endpoint domain; `$<Model>` selects anonymously. The existing union, scope, identity, and whole-population cardinality rules below remain unchanged. No global all-$ selection is implied.

`$container[<Workflow Run> OR <Step Run>]` binds one participant over the union of the specified instance domains. A Relation bound such as `{::1}` applies once over that whole union, not separately to each kind. `$<Journal>{::1}` and `$journal[<Journal>]{::1}` each constrain the selected logical Journal instance population within the Current Project to exactly one. A variable introduced by a standalone typed instance selector remains in scope for following statements in the same CFEL fenced block. A variable introduced in an IF condition is in scope within that condition and its matching THEN group only; it is not in scope in following statements. A new IF binding uses a different name from an already bound outer variable; references to that outer variable retain its identity.
