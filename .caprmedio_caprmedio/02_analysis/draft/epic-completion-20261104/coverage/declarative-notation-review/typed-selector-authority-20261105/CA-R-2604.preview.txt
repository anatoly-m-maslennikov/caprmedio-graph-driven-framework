## Summary

Declare CFEL operator $

## Claim

### Formal Claim

```CFEL
# model
Operator//InstanceBinding == "$"
```

## Semantics

Bind an existing selected instance or read its bound Property; it creates nothing. `<Kind>` references a declared Model kind. `$x[<Kind>, (conditions)]` is the successor spelling of `Kind//$x`: it binds an existing instance of that kind as a named participant, subject to grouped conditions evaluated against that participant. `$<Kind>` is the anonymous successor spelling of `Kind//`. Repeated anonymous selections use the same domain but do not assert that their referents are identical or different; use a named participant to assert the same selected identity. These expressions create nothing and do not turn a model entity into a data-layer fact. A variable introduced by a standalone typed instance selector such as `Kind//$x;` or `$x[<Kind>];` remains in scope for following statements in the same CFEL fenced block. A variable introduced in an IF condition is in scope within that condition and its matching THEN group only; it is not in scope in following statements. If an outer variable is already bound, a new binding inside IF must use a different variable name; references to the outer variable retain its existing identity.
