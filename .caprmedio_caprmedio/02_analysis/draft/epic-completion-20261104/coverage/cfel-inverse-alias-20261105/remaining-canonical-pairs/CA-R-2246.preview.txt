## Summary

Define RECORDS Relation

## Claim

### Formal Claim

```CFEL
# model
Relation//IS_RECORDED_BY ((IS_INVERSE_ALIAS_FOR)) Relation//RECORDS;

Relation//RECORDS ((HAS_CLASSIFICATION)) Derivation == Direct;

# instances
$event_record[<Event Record>]((RECORDS)) $event[<Event>]
```

## Semantics

RECORDS relates an Event Record to the Event it describes. IS_RECORDED_BY is its inverse alias; an Event Record is distinct from the Event.
