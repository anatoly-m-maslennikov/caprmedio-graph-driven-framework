# Confidence and retry reconciliation — Draft

This packet is a proposal, not Current authority or runtime behavior. The latest decision makes a Plan's Header AI Agent Confidence Threshold optional; resolve the current Plan, then each enclosing Plan in `IS_CONTAINED_BY` order, then the required `Project.Settings.AI Agent Confidence Threshold` (CA-R-2564@2). It removes the Plan retry Property and assigns retry to Workflow; no Workflow instance, Workflow Run Property, settings key, or new retry default is authorized by that decision. Pinned sources, preview hashes and exact selected-frontier consumers are in `manifest.json`.
