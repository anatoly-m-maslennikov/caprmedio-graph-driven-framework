## Summary

Permit confidence-threshold defaults and overrides

## Claim

### Prose Claim


the source of a Confidence Threshold value.


a Plan's AI Agent Confidence Threshold **must** resolve from its explicit Header value, then the nearest enclosing Plan with an explicit value by recursively following `IS_CONTAINED_BY`, then the required `Project.Settings.AI Agent Confidence Threshold`. An omitted Plan value is not copied locally; invalid or ambiguous reached sources require Operator disposition without silent fallback.
