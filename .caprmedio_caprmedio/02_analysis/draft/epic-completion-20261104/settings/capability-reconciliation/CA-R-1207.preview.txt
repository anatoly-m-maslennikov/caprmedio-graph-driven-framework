## Summary

Separate Project Configuration Rules from Current Settings

## Claim

### Prose Claim


Ownership of Project-specific expansion rules, constraints, and defaults, separate from current capability selections.


the Project Configuration **must** own Project-specific expansion rules, constraints, **and** defaults **only** **where** the Core Meta-Model permits expansion; where capability selections are applicable, their current values **and** selected revisions **must** remain owned by the governing Framework Instance Settings Artifact, **not** duplicated **in** Project Configuration Atoms.
