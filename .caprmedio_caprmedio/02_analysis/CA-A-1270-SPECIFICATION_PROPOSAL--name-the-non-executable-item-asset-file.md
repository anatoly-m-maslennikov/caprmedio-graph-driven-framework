# Summary

Name the non-executable item Asset File

## Decision

Use Asset File as the primary-kind name in the approved Package structure. It is the non-executable file-level Implementation item needed by runtime or tests. Its logical role remains distinct from File Carrier. Replace the prepared Asset declaration with Asset File; no alias is introduced. Keep the older unnumbered Asset Draft explicitly superseded for existing historical links, not as another promotion target.

## State

Proposal and prepared Draft updates only. Current methodology, governing configuration, historical reports and implementation are unchanged.
