# FPF is not yet a CAPRMEDIO-aligned Project Extension

The current FPF sources and installations do not establish one immutable CAPRMEDIO Extension that is project-local, directly invokable as `$fpf`, governed by current CAPRMEDIO authority, capable of persisting correctly formed and placed Analysis Report and Concern Atoms on explicit Operator request, and connected to canonical asynchronous Tool execution through MCP with safe lifecycle controls; therefore they cannot yet be treated as one installed and active CAPRMEDIO-aligned FPF realization.
