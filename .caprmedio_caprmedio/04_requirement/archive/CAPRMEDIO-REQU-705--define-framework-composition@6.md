# Define Framework composition

The CAPRMEDIO Framework must consist of FRAMEWORK_METHODOLOGY plus FRAMEWORK_ENGINE. OPERATOR_DOCUMENTATION is a downstream Project Layer; EXTENSIONS and RELEASES are unordered direct Project Features; FIELD is an unordered direct Project child. None of these downstream units is a constituent of the Framework itself.
