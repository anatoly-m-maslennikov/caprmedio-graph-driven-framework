# Own cross-unit relational Atoms at the common scope

Within the current project, every relational Atom whose exact endpoints occupy different descendant Structural branches belongs to their narrowest enabled common Structural scope. CAPRMEDIO owns only relational Atoms whose endpoint set crosses immediate CAPRMEDIO-child branches or includes CAPRMEDIO itself.
