# Define implementation layer scope and contracts

PROJECT assigns IMPLEMENTATION the actual source, documentation, configuration, tests, evaluations, and other realized project artifacts, plus their traceability to applicable SPEC authority. IMPLEMENTATION consumes applicable PROJECT, META, GOV, and SPEC authority and supplies a realizable project unit to DELIVERY and operable surfaces to OPS.
