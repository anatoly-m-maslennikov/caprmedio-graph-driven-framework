# Select optional capabilities through Configuration

CAPRMEDIO **must** govern Project-owned Configuration that selects, combines, parameterizes, **or** disables available optional canonical **and** Extension capabilities **only** within declared configuration boundaries **and** **without** redefining governed meanings.
