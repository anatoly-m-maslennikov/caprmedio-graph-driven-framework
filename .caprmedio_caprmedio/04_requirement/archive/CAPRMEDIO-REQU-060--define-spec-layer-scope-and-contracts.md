# Define SPEC layer scope and contracts

PROJECT assigns SPEC the applicable Requirement, Method, Evaluation, and Delivery authority that defines what and how the project must realize. SPEC consumes applicable PROJECT, META, and GOV authority and supplies the normative project specification to IMPLEMENTATION and every later Layer; it does not own the realized artifacts.
