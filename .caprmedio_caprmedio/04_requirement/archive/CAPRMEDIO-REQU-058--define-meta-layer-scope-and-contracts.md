# Define META layer scope and contracts

META is Layer 1 and owns the project ontology: canonical vocabulary, semantic axes and distinctions, Content-role and artifact-form meanings, applicability tiers, relation meanings, structural interpretation, and construct-admission rules. META consumes applicable PROJECT authority and supplies those meanings to every later Layer; it does not own concrete Layer topology, carrier mechanics, project behavior, or realization.
