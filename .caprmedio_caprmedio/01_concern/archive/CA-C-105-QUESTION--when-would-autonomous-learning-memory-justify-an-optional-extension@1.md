# When would autonomous learning memory justify an optional Extension?

This Concern is derived from CA-A-060 and concerns the optional reusable
capability boundary in CA-R-831.

WHEN would measured project need, integrity evidence, and operator-governed
promotion controls justify an optional autonomous-learning-memory Extension
whose disposable runtime state remains subordinate to one canonical project
graph?
