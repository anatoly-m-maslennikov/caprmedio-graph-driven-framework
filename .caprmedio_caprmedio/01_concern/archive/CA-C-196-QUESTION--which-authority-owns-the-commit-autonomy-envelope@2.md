# Which authority owns the commit-autonomy envelope?

which R, D **and** O owners preserve the complete commit-autonomy envelope **without** replacing the Operator's selected permissions **or** weakening its independent-authorization safeguard?

## Evidence

R-1385 requires one durable current envelope, specifies exact bound fields **and** allowed effect kinds, orders revalidation **before** admission, dispatch **and** commit, defines pause/replacement/resumption behavior, **and** requires the authorizer **to** differ from the effect worker. M-182 repeats that boundary alongside manager/Scheduler construction choices. these are distinct required outcomes, Carrier representation **and** Actor/Action contributions; naming one role alone does **not** resolve them.

## Principle check

Operator authority **and** configurability preserve the selected permission boundary; neither implies that a mandatory separation-of-authorizer safeguard can be removed. DRY requires reusing its exact source rather than a second envelope definition. coherence **and** information preservation require retaining expiry, Work binding, caps, circuit state, stable action identity **and** recovery gates across **any** split.

## Disposition

preserve the complete envelope pending a lossless R/D/O ownership map **and** the exact source of its selected values. retain the local real-change **or** Journal-**only** commit limit **and** **all** excluded Git effects. do **not** invent an Actor, relax independent authorization, infer permission from a confidence threshold, **or** turn preservation/narrowing into permission for expansion. reuse C-180 for optional Git integration **and** C-179 for Initiative identity. no service, permission **or** Settings value is changed here.
