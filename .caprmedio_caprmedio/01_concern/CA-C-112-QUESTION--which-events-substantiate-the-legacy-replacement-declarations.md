# Which events substantiate the legacy replacement declarations?

which recorded predecessor-archive events substantiate the replacement declarations removed from **19** active Atom Carriers under CA-R-807?

## Evidence

the obsolete `replacement_of` declarations are preserved exactly **in** the listed Carriers' archived before-states. the correction Journal records **only** the observed archive **and** current-state cleanup; it does **not** assert that a past replacement occurred **or** fabricate its time, approval, predecessor state, **or** active successors.

## Principle check

CA-M-002 rejects duplicated current authority **and** CA-R-1490 requires recoverable history. CA-R-807 reserves replacement history **to** the actual predecessor-archive event. those rules justify removing the forbidden active relations but cannot prove an unobserved historical transition.

## Disposition

deferred under the Operator's uncertainty policy. resolve **every** declaration against existing immutable Journal **and** archive evidence. preserve unsupported declarations as historical evidence **without** promoting them **to** factual replacement events. no active Claim was removed **or** rewritten by this cleanup.
