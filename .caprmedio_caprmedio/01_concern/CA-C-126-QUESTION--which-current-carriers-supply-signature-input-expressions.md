# Which current Carriers supply signature input expressions?

which current governed Carrier fields **or** content selections supply the input expressions for Canonical Signature **and** Canonical Scope Signature discovery?

## Evidence

- CA-M-240 restricts discovery **to** active single-statement Claims, while CA-M-301 admits structured composite Claims. R-1360 defines a restricted expression occurrence, **not** a one-sentence Atom format.
- CA-M-241 requires **=1** unwrapped Scope Expression **in** a literal `## Scope` section. current Claim Structural Entity/Claim Scope Unit authority is being reconciled under C-118/C-125; no inspected rule establishes that legacy section as the universal current source.
- R-1361's homogeneous nested-group grammar has been reconciled with E-407. that semantic grammar does **not** select an Atom section, authorize a new stored Scope Property, **or** establish a discovery boundary for **all** current Atom Types.
- the Methods also contain Tool execution/output instructions that need coordinated O/D ownership. changing their Content Role alone would preserve an unresolved input contract.

## Principle check

CA-M-002 prohibits a duplicate Scope field merely **to** preserve an old Tool parser. CA-M-005 rejects an invented universal section. CA-M-006 requires grammar, source selection, check coverage, **and** Carrier authority **to** agree.

## Disposition

defer the uncertain discovery/input binding. preserve the current non-authoritative comparison, no-source-rewrite, exclusion, **and** provenance guarantees. reconcile the exact input selector **before** replacing M-240/M-241 **and** their Tool-facing consumers. do **not** alter Tool implementations **or** certify discovery completeness from a grammar-only repair.
