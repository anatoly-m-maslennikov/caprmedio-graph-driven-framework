# Which target authority may ATOM_UPGRADE admit?

which target-tier selections **and** contextual Claim-preservation conditions **may** ATOM_UPGRADE admit under the current Local Tier **and** Scope Unit model?

## Evidence

CA-R-870, its extracted CA-O-045 Action, **and** CA-E-308 retain the explicit `core` **or** `standard` target restriction **and** same-owner **or** named-ancestor behavior. CA-D-426 retains the executable binding. CA-R-155 admits Principle, Core, General, **and** Standard contextually; CA-R-1442 orders Core above General above Standard outside the Project, while CA-R-680 restricts the Project's own tier set.

admitting General **or** Principle through this Tool would widen its current explicit permission, **not** merely change a spelling. an ancestor move can also change the omitted Claim Scope Unit **and** relative references; CA-C-119 already records the general cross-owner move concern. a same-owner higher Local Tier **and** an ancestor's Standard tier **must not** be compared by an assumed local-label ordering alone.

## Principle check

CA-M-002 requires reuse of the canonical tier authority; CA-M-006 requires coherent scope **and** authority resolution. CA-M-005 rejects an invented extra tier system, **and** CA-R-1490 preserves the accepted boundary **and** evidence. these Principles do **not** establish whether ATOM_UPGRADE intentionally supports a restricted target subset **or** is supposed **to** support **every** contextually admitted higher target, nor do they authorize silent widening of a Claim through relocation.

## Disposition

deferred under the Operator's uncertainty policy. preserve the existing target restrictions while retaining the completed M-to-O role correction **and** post-effect recovery coverage. resolve target admission, Global Tier comparison, **and** scope-preserving versus Claim-changing ancestor moves together with CA-C-119; **then** reconcile R-870, O-045, E-308, **and** D-426. no live upgrade **or** implementation change was performed, **and** this Concern does **not** certify the existing restricted behavior as fully aligned.
