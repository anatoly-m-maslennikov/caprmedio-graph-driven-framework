# Which Relation Kind supports the redundant transitive-edge fixture?

which registered Relation Kind **and** derivation rule make E-113's additional transitive edge redundant?

## Evidence

E-113 assumes a direct path entails a transitive semantic edge, **without** selecting the Relation Kind. R-806 requires graph ownership, transitivity **and** exclusive purpose **in** the registration; R-808 prohibits a universal ordering rule across domains. R-1024 prohibits a registered direct relation from implying a transitive relation, while R-1498 explicitly derives recursive Structural Entity containment by transitive closure. those are **not** interchangeable domains **or** fixtures.

## Principle check

DRY rejects independently maintained duplicate facts, **not** **every** additional edge between reachable nodes. coherence requires the exact registered meaning **before** deciding equivalence. information preservation protects independently meaningful direct relations **and** valid derived views.

## Disposition

preserve E-113 **until** its intended graph-qualified Relation Kind, direct declaration **and** admitted derived fact are explicit. do **not** delete an edge solely because another path connects its endpoints, reinterpret **all** direct relations as transitive, **or** infer a universal transitive-reduction algorithm. preserve the stable non-direct-relation diagnostic **only** **where** the selected authority actually warrants it. no graph **or** Tool is changed here.
