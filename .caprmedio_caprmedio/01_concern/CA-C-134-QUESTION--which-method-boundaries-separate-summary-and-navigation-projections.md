# Which Method boundaries separate Summary and navigation Projections?

which independently governed Method Claims preserve Summary creation **and** requested navigation Projections **without** duplicate derivation authority **or** an invented shared Subject?

## Evidence

- CA-M-116 **and** CA-M-231 overlap in deriving navigation information from a complete Claim, retaining an existing Summary, **and** respecting CA-R-1464 replacement. M-116 also refers **to** simpler wording under M-294; M-231 explicitly retains target applicability **and** rejects using Summary as the source of other requested Projections.
- CA-M-111 repeats Summary **and** Translation derivation inside its numbered authoring instructions.
- R-1465 makes Summary an Atom Property with no independent lifecycle; R-1464 fixes it for the Atom identity. requested Translations **and** other Projections have their own source-governed derivation behavior.
- the Methods use different legacy governing targets, `Atom Claim Projection` **and** `Navigation Projection Derivation`. an invented common target would hide rather than resolve the one-governed-target boundary. C-111 **and** C-125 separately cover canonical Subject **and** Scope Property uncertainty.

## Principle check

CA-M-002 requires deduplication; CA-M-005 rejects an extra Entity merely **to** merge files; CA-M-006 requires consistent Property **and** Projection lifecycles; CA-R-1490 protects source faithfulness, complete applicability, simpler wording, **and** the fixed-Summary constraint. CA-R-1270 permits a composite Claim **only** with a shared authority lifecycle. those Principles do **not** justify merging independently replaceable Summary **and** Projection responsibilities **or** treating an authoring checklist as a new reusable Action **without** its justified boundary.

## Disposition

preserve M-111, M-116, **and** M-231 until the exact reusable Method boundaries **and** canonical targets are established. reuse existing Summary **and** general Projection authority; extract executable construction **only** where the Claim actually defines an Action **or** Process. do **not** rewrite Summary values **or** generated Projections during this repair.
