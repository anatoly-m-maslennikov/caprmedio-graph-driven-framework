# Which authority owns admission and promotion behavior?

which independently governed admission criteria, Actor permissions, **and** Operations replace GOV-REQU-302 **without** changing its strictness **or** promotion boundaries?

## Evidence

GOV-REQU-302 v22 admits medium **and** high atomic strictness, lists the information required for stable admission, permits explicitly unknown optional context, requires focused clarification at high strictness, limits promotion **to** a Claim unchanged at a broader enabled scope, requires explicit Operator acceptance, **and** preserves later Revision **and** replacement distinctions. R-1432 separately classifies changes. GOV-REQU-385 distinguishes classification failure from universal mutation prohibition, **and** R-1439 keeps reporting mode presentation-only.

## Principle check

CA-M-002 requires reuse of existing change classification **and** permissions; CA-M-006 requires R criteria **and** O behavior **to** agree; CA-R-1490 protects the promotion gate **and** optional-unknown allowance. imperative words alone do **not** make **every** admission condition an Operation. the inspected sources do **not** establish a complete Action boundary **or** identify which duplicated criteria can be removed **without** a gap.

## Disposition

preserve GOV-REQU-302 pending a complete obligation mapping. distinguish validity criteria from participation policy **and** execution behavior; do **not** replace the two strictness values with Authority Modes, infer promotion permission, make optional context mandatory, **or** disable later same-ID Revisions. no Settings value **or** Tool behavior is changed by this Concern.
