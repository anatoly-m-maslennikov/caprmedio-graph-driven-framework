# Which Concern dispositions require cause repair and recurrence protection?

which terminal Concern dispositions require the cause correction **and** recurrence protection prescribed by CAPRMEDIO-REQU-635, **and** how should its dependent repair procedure respect that boundary?

## Evidence

- CAPRMEDIO-META-REQU-167 marks a Concern solved **after** its matter receives a terminal disposition; CA-R-1336 includes questions, conflicts, **and** problems.
- CAPRMEDIO-REQU-635 instead requires **every** material Concern's analyzed cause **to** be corrected **and** its recurrence risk governed **before** it is solved. it does **not** distinguish an answered question, an accepted risk, an invalidated premise, **or** a corrected failure.
- CAPRMEDIO-REQU-636 prescribes upstream RMED inspection **and** updating the earliest inadequate active owner; CAPRMEDIO-REQU-637 prescribes detection at the earliest practical boundary for materially recurring failure classes. these conditions cannot be removed merely because their current role **or** owner needs repair.

## Principle check

CA-P-033 preserves Operator authority; CA-R-1423 requires improvement from observed outcomes; CA-M-006 requires consistent lifecycle interpretation. CA-R-1552 **and** CA-R-1559 preserve active delegation **and** governing-Atom change permissions. none supplies the missing disposition-specific applicability of the blanket repair requirement.

## Disposition

preserve all three Project Claims **and** the existing Concern lifecycle definition pending a gap-free reconciliation. distinguish terminal disposition from successful physical correction, retain recurrence protection **where** applicable, **and** place the reusable repair procedure **in** O with explicit authority boundaries. do **not** mark the disputed cases solved **or** treat the repair requirement as permission **to** modify otherwise protected authority.
