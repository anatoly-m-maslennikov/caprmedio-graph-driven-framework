# What Action boundaries preserve identity-collision repair?

which reusable Action boundaries **and** explicit Process flow should replace CA-M-276's identity-collision repair procedure **without** weakening its evidence, authorization, reference-preservation, **or** stop conditions?

## Evidence

- CA-M-276 identifies distinct source Atoms, establishes the original valid owner, assigns unused identifiers **only** **to** accidental reuse, repairs individually resolved references, validates the result, **and** refreshes affected Projections. CA-E-448 checks these distinct failure cases.
- CA-R-1452 requires a justified atomic responsibility. calling this complete multi-effect procedure one Action merely because it repairs one collision would **not** establish that boundary.
- CA-R-1453 requires referenced Action nodes **and** explicit control flow for a Process. no inspected current flow establishes the exact reusable nodes **or** a safe restart boundary **after** a partial identity/reference repair. a Method-to-Process filename change alone would **not** provide them.
- CA-D-450 now owns number allocation constraints; CA-R-728 retains immutable valid identity. neither authorizes selecting the original owner from discovery order **or** automatically repairing sources during lookup.

## Principle check

CA-M-002 requires reuse rather than competing repair mechanisms; CA-M-005 requires meaningful Action boundaries; CA-M-006 requires the flow **and** checks **to** agree; CA-R-1490 preserves identity history **and** intended reference targets. these Principles resolve the need for O ownership but do **not** identify a safe decomposition **or** authorize new rollback behavior.

## Disposition

defer this exact decomposition below the Operator's confidence threshold **and** continue the remaining audit. retain CA-M-276 **and** CA-E-448's current safeguards. resolve reusable nodes, branch conditions, partial-effect handling, **and** the existing Operator escalation points **before** replacement; do **not** execute a collision repair **or** add Tool mechanics as part of this source review.
