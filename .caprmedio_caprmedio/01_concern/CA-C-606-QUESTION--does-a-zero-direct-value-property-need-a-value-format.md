## Summary

Does a zero-direct-value property need a value Format?

## Question

Should the provisional choice below become the final model rule?

## Details

For a grouping property with cardinality {0}, state that a direct-value Format is not applicable; define the Formats of its children independently. Do not invent void/list/map as Formats. This reconciles the required property coverage with the approved direct-value semantics.

The Operator authorized the best-supported choice plus a recorded Question when the last 48 hours do not settle it. Continue P2683; this is not a request to pause. Tracked in CA-A-1305 with Candidate CA-A-1302.
