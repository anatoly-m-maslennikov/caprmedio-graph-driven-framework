# Which Project Core rules are product commitments rather than reusable Methodology?

which of the listed Project-owned rules retain a distinct caprmedio product commitment, **and** which must become reusable Methodology authority **without** changing their intended targets, Type meanings, **or** dependent authority?

## Evidence

the listed structural, conflict, casual-mode, improvement, priority-comparison, reconstruction, **and** Evaluation rules use broadly reusable wording. M-093 through M-100 are conditional comparison criteria, **not** current priority selections **or** permission **to** disable mandatory authority; they **must not** be copied into Settings as selected values. M-262 supplies runtime equivalence **and** sufficient-authority conditions distinct from the short reconstruction Principle. M-105 combines canonical-definition reuse with an unresolved-definition escalation branch. E-438, E-439, **and** E-442 check the selected mode, implementation flow, **and** pre-refactoring safeguards rather than one particular completed implementation.

## Principle check

CA-M-002 requires one authority for **every** purpose **in** the same context; CA-M-005 requires preservation of a material distinction; CA-M-006 requires coherent ownership, roles, **and** Type admission. broad applicability alone does **not** prove that a Project product requirement is a duplicate definition. C-117 records the absent authoritative Project Structure; C-119 records owner-dependent meaning on moves; C-152 records Core usage of configured Types. none is solved by changing a folder name **or** interpreting `IMPL_METHOD` as a different admitted Type.

## Disposition

preserve the inspected Claims while resolving their exact purpose against current Principles **and** Methodology counterparts. consolidate only proven duplicates; move reusable rules **only** with a target, reference, **and** Type preservation map. retain genuinely Project-specific capability commitments. this is a bounded ownership question, **not** acceptance of general-purpose Atoms permanently remaining **in** Project authority.
