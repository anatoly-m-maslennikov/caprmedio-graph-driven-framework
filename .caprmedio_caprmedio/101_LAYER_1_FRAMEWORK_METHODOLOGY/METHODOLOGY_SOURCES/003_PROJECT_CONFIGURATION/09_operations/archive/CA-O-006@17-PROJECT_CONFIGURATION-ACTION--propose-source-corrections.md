# Summary

Propose source corrections

## Operation

Propose Source Corrections **means** the reusable Action that prepares an explicit correction for an identified conflict **in** one exact selected source frontier.

1. use the current assessment from CA-O-005, including Global Tier, Updated At, **and** Principle alignment. identify the affected source authority, exact proposed change, intended outcome, effects, **and** uncertainty.
2. consider archiving a conflicting Atom **when** removing its active authority improves alignment with the Principles. do **not** retain an obsolete Atom merely because it already exists.
3. **before** proposing archival, account for **every** still-required Claim **and** affected reference, Relation, Evaluation, **and** dependent authority. identify its remaining active owner **or** the exact prerequisite repair; do **not** invent a successor for a Claim that governing authority explicitly withdraws.
4. leave no gap **in** the affected authority: missing coverage, dangling active references, lost required checks, **or** an unresolved conflict blocks completion. required replacement **or** absorption successors **must** be Active **before** the predecessor is archived. unique valid content **must** be preserved **before** removing the mixed Atom.
5. target corrections **only** at their owning source through its governed change workflow, **not** at a derived copy. preserve the exact archival history **and** record replacement **or** absorption under CA-R-807.
6. return the proposal **and** its authorization needs. **if** no sufficiently supported gap-free correction fits the applicable authority **and** confidence constraints, report the exact uncertainty for Operator escalation.

a proposal does **not** authorize **or** perform the change. no duplicate authority **must** be created merely **to** make archival possible.
