# Classify Development Backlog as Plan

CAPRMEDIO must classify the Development Backlog as a Plan containing accepted intended action points. Its default carrier may allocate action points through unscheduled and target-version sections in one file; a target-version section becomes a separate Version Plan only after an operator-approved split. This replaces the obsolete Development Backlog Projection authority.
