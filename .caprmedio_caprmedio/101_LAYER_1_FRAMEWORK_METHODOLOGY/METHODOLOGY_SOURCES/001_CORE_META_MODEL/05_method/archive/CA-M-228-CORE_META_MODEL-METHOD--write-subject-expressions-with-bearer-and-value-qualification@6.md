# Write Subject Expressions with Bearer and Value Qualification

**to** write a Subject Expression, start with one Primary Entity, append **every** bearer-dependent occurrence with `/`, append **every** allowed value with `:`, **and** continue qualification **only** from the resulting qualified occurrence.
