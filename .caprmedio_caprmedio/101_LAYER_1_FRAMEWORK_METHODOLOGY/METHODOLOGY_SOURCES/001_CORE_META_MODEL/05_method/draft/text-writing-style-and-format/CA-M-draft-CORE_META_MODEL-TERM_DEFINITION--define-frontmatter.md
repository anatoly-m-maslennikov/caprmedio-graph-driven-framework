## Summary

Define Frontmatter

## Claim

Frontmatter means the YAML part at the beginning of a Markdown Atom Carrier.

## Semantics

It is the structured metadata region of that carrier. The Term names the region; Delivery rules settle its delimiters, permitted fields, key spelling, nesting and value encodings.
