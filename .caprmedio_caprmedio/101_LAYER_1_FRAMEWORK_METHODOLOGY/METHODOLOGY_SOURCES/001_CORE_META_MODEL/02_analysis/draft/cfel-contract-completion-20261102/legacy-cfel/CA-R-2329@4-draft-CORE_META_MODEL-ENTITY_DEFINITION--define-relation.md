## Summary

Define Relation

## Claim

Relation is CFEL notation for expressing a named directed connection. A
declared derived counterpart is optional.

### Formal claim

```CFEL
CFEL <+ Relation
```

Relation endpoint, direction and cardinality contracts are declared by the
canonical and derived Relation Declarations.

The notation describes CFEL representation; it does not author a Graph
Relation or an operator.
