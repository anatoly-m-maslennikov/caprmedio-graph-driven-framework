## Summary

Define Cardinality

## Claim

Cardinality is CFEL syntax for expressing the allowed number of direct values,
dependent Properties, Relation instances or contained parts.

### Formal claim

```CFEL
CFEL <+ Cardinality
```

The forms are `{:n}`, `{:n+}` and `{:n..m}` with non-negative integer bounds.
