# Give Every Atom Revision One Authoritative Carrier Bundle

**every** Atom Revision **must** have **`=1`** authoritative Carrier Bundle on the Project filesystem containing **`>=1`** Carrier; the applicable Delivery rule determines its permitted Carrier kinds **and** whether multiple same-identity Carriers jointly materialize that one Revision.
