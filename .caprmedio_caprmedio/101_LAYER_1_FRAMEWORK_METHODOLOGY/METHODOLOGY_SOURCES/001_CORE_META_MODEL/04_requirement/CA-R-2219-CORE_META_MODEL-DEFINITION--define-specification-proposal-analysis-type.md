# Summary

Define Specification Proposal Analysis Type

## Scope

Specification Proposal Analysis Type in the proposed Subject model.

## Claim

Specification Proposal is an Analysis Type that presents a proposed specification for review before its adoption into governing RMED.

## Semantics

It records the proposed structure and its supporting source definitions without becoming normative authority. Each accepted review decision is recorded in its own Specification Proposal file. Plans hold work and progress and link to the proposal rather than copying its decision text.
