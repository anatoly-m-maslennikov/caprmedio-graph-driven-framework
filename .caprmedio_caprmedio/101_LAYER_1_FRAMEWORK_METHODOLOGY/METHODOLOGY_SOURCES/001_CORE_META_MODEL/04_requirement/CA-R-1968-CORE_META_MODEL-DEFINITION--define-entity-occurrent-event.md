# Summary

Define Entity/Occurrent/Event

## Scope

Events as Occurrents.

## Claim

an Event **means** an actual occurrence. an Event happening in a Runtime is an Occurrent. a record describing the Event is **not** the Event itself.

## Semantics

The Event is what actually happens. An Event Record in a Journal describes that Event and is a Continuant. The Journal contains Event Records, not the actual Events.
