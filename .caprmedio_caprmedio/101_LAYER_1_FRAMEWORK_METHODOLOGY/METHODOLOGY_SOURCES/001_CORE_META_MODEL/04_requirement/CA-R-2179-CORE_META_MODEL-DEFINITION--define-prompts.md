# Summary

Define Prompts

## Claim

Prompts **mean** Implementation runbooks, how-tos and instructions, primarily for LLMs. They guide an Actor in performing work.

## Semantics

Instructional purpose defines this category. LLMs are the main audience, not the only permitted audience.
