# Distinguish Implementation Methods from Implementation Decisions

An Implementation Method governs reusable policy for how accepted specification is realized, while an Implementation Decision selects one concrete approach for a bounded realization target. **none** **in** (Implementation Method, Implementation Decision) is an execution Plan **or** native Implementation.
