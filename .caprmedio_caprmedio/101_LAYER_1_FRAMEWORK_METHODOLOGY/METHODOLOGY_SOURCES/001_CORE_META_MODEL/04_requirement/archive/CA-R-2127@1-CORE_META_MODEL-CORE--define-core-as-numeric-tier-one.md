# Summary

Define Core as Numeric Tier 1

## Scope

the numeric Tier value 1 and its initial display name Core.

## Claim

Tier `1` has the initial display name Core and means the foundational specification tier that establishes the model premises and boundaries governing Atoms at greater numeric Tiers in the same Scope Unit. It includes General and Standard Atoms across Content Roles, without gaining its meaning from a Content Role or Type.

These foundations establish identity, purpose, authority ownership, fundamental separation, or conservation boundaries. Governing target ordering is defined independently by CA-R-2149; no Global Tier is stored or compared.
