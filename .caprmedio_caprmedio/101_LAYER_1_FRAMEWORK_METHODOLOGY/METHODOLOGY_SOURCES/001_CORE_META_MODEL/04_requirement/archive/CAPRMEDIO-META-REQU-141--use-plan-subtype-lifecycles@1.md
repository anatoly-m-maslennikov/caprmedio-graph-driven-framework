# Use Plan subtype lifecycles

CAPRMEDIO must apply subtype-specific lifecycles while keeping every Plan action-only and structurally single-scope. A Development Backlog may remain active; Version, Change, and Refactoring Plans terminate in `done/` or `archive/` as applicable. Findings, alternatives, interpretation, and rationale remain Analysis rather than Plan content. This replaces the obsolete universal short-lived Plan rule.
