# Summary

Define the Operations Content Role

## Scope

the Content Role value Operations.

## Claim

the Content Role value Operations **means** the Content Role of an Atom whose Claim defines specific reusable Action behavior, Workflow graph, **or** Step definition for performing governed work. a Step definition may be a leaf Action invocation or a containing Step structure; the Action remains separate and reusable across Step and Workflow references.
