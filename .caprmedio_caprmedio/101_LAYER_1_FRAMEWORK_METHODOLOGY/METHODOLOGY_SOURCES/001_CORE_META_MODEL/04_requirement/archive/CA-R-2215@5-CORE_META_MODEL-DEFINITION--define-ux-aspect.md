## Summary

Define UX Aspect

## Claim scope

UX Aspect in the Subject model.

## Claim

The UX Aspect addresses how an Actor discovers, understands and uses an interface and receives its results.

### Formal claim

```text
UX/Discovery and Navigation
UX/Entry
```

## Semantics

It includes model-facing interfaces such as MCP as well as human-facing interfaces. It does not name a specific Tool, page or application.
