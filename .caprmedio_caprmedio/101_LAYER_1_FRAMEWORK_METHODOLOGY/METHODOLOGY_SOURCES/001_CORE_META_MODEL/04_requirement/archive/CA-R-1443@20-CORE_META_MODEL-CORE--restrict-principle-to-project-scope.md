# Summary

Restrict Principle to Project Scope

## Scope

Atoms with numeric Tier 0, whose initial display name is Principle.

## Claim

an Atom **may** use numeric Tier **`0`** (the initial display name Principle) **only** **if** its current Scope Unit **`=`** the Project. This scope rule does not impose a Content-Role or Type-to-Tier restriction on other admitted numeric Tiers.
