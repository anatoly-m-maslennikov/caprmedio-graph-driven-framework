## Summary

Define Governing Objects

## Claim

Governing Objects classifies authored project/model source objects, including Atoms and Governing Configurations. Each retains its own role, type and authority; the classification grants no additional execution permission.

### Formal claim

```text
Continuant/Governing Objects
Governing Objects / @(Atom)
Governing Objects / @(Governing Configuration)
```

## Semantics

Governing Objects classifies the authored project/model source objects. Each Atom retains its Content Role and Type meaning and authority; this grouping does not turn a completed Analysis report into a normative Requirement or grant execution permissions.
