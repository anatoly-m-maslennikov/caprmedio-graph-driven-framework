## Summary

Define Evaluation Type Eval Policy

## Claim
Eval Policy is a reusable Evaluation Type that prescribes a mechanism-neutral evaluation approach for a class of subjects or behaviors.

An Eval Policy may state a representation-independent evaluation policy without an artificial list of individual targets.

## Semantics

It can be realized by one or more mechanisms. It is not an Eval Case, implementation, test suite, or one-to-one mechanism mapping. The canonical Type name is Eval Policy; it creates no Tier restriction.
