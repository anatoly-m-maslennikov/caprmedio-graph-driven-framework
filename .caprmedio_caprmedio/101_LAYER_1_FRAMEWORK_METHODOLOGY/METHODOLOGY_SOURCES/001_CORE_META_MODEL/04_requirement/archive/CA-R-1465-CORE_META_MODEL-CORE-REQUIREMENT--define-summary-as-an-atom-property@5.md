# Define Summary as an Atom Property

a Summary **means** a concise non-authoritative navigation Property of **`=1`** Atom, derived from that Atom's complete Claim **and**, **when** present, Claim Scope. it belongs **to** that Atom **without** independent identity, lifecycle, **or** authority.
