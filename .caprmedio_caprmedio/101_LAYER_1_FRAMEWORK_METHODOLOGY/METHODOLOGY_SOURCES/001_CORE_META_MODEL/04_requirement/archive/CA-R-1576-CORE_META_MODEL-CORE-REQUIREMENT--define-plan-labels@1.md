# Define Plan Labels

a Plan Label **means** a mutable navigation **and** understanding aid, such as Version, Objective, Epic, Sub-epic, Mega-epic, Task, **or** Subtask; it does **not** establish a distinct Type, authoring Subtype, identity, completion rule, **or** execution dependency.
