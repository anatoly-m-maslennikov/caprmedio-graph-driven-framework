## Scope

Goal Atoms.

## Claim

a Goal Atom **means** a Relational Atom with Content Role Requirement **and** Type Goal whose Claim states one desired result for **`=1`** non-Project Target Scope Unit. A Goal targeting the Project uses the distinct Type Project Goal; its Operator-owner exception does not apply to ordinary Goal Atoms.
