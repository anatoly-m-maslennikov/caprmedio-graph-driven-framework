# Summary

Define Subject Target Roots

## Scope

Canonical Subject paths.

## Claim

Bare Subject is the umbrella. A more-specific canonical Subject path enters Graph Node, Graph Relation or Graph Rule. Graph Node admits Domain, Engineering, Implementation, Runtime, Carrier, Product, UX and Documentation as open Subject branches. Engineering directly names aspects and practices. Implementation names logical Code, Prompts, Documentation and Resources. Runtime names actual technical execution contexts. Carrier names representations and storage. Domain retains its modeled Continuants and Occurrents; Release belongs to Domain/Continuant/History/Release.

## Semantics

These are Subject branches, not Content Roles or Scope Units. Engineering has no separate Aspect, Continuant or Occurrent path layer in Candidate #9. Modeled Action, Step and Workflow Runs remain Domain occurrences; technical sessions and process/container execution belong to Runtime. The Graph Node branch is a path namespace, not another represented object. Graph Relation and Graph Rule remain global Subject branches. Existing Product, UX and Documentation topics retain their meanings.
