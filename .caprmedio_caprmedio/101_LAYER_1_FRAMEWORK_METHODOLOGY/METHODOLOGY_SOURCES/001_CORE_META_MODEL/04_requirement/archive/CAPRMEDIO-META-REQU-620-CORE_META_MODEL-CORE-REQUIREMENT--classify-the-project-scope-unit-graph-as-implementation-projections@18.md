# Project current structure without creating authority

a Project Scope Unit Graph Projection **means** a read-only view derived from selected Project Structure declarations, relevant Atom authority, effective Settings, **and** observed Scope Unit Carriers. it is distinct from authoritative Project Structure **and** **must not** independently establish **or** change those facts. declared units, their Goal-coverage gaps, missing materialization, **and** undeclared observed candidate units remain distinguishable; Draft **and** archived Atoms supply historical evidence **without** becoming active authority.
