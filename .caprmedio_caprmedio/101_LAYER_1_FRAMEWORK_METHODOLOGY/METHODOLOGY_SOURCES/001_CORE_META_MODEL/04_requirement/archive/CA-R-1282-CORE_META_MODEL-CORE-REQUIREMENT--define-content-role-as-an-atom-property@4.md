# Define Content Role as an Atom Property

Content Role **means** the Atom Property that classifies the primary contribution of one Atom Claim, **not** **only** the Operation **or** Actor that the Claim mentions. a meta-model definition of Operations **may** remain Requirement because defining the role is distinct from providing an operational procedure **or** participation policy.
