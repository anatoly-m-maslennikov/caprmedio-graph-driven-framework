## Summary

Define UX Aspect

## Claim scope

UX Aspect in the Subject model.

## Claim

Guidance concerns helping an Actor choose and use capabilities. Interaction concerns the exchange with the Actor; Accessibility and Decision narrow that exchange. Result and Status Presentation concerns how results and progress are shown, independently of their backend production. These are reusable topics rather than named interfaces or Scope Units.

The UX Aspect addresses how an Actor discovers, understands and uses an interface and receives its results.

## Semantics

It includes model-facing interfaces such as MCP as well as human-facing interfaces. It does not name a specific Tool, page or application.
