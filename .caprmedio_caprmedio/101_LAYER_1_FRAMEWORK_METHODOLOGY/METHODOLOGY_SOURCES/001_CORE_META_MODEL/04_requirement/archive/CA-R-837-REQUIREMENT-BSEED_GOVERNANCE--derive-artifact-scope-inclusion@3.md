# Derive Artifact scope inclusion

GOVERNANCE must derive each Artifact's one direct Scope Unit from its canonical carrier address and include that Artifact in every Scope Unit on the direct Unit's complete ancestor path; missing, multiple, unknown, or cyclic scope ownership is invalid.
