# Summary

Define CAPRMEDIO Subject namespace

## Scope

CAPRMEDIO Subject namespace in the proposed Subject model.

## Claim

The CAPRMEDIO Subject namespace qualifies the shared vocabulary supplied by the CAPRMEDIO framework. It separates that vocabulary from a project’s own subjects.

## Semantics

This namespace is a qualification and grouping, not another entity kind, Product instance or Scope Unit. An Atom can refer to a Subject here regardless of its owning Scope Unit.
