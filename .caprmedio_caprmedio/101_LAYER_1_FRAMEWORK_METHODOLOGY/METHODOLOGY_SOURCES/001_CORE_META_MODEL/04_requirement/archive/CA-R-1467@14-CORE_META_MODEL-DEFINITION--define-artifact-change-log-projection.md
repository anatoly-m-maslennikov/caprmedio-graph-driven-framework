# Summary
Define Artifact Change Log Projection

## Scope
Artifact Change Log Projections of Project Journal records that present recorded Artifact changes.

## Claim

an Artifact Change Log **means** a non-authoritative Projection of the Project Journal that presents recorded Artifact changes **and** preserves their canonical Event identities **and** source record references. it does **not** independently author historical facts **or** require an Artifact change for an execution that changed no Artifact.
