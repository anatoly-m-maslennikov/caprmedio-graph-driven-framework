# Summary

Assign Project Goal Tier Minus One

## Scope

Project Goal Atoms.

## Claim

Every Project Goal Atom **must** be owned by the Project and carry exactly one numeric Tier `-1`. Tier `-1` is explicit, is not omitted, and is not one of the initial display names 0 Principle, 1 Core, 2 General, or 3 Standard. This Rule does not impose an arbitrary Type-to-Tier restriction beyond verified Project Goal identity and ownership.
