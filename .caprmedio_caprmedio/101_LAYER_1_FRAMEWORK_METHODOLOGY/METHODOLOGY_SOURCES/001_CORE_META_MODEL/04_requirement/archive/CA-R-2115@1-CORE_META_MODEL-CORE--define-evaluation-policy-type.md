# Summary

Define Atom/Content Role: Evaluation/Type: Policy

## Scope

The Policy value in the qualified Evaluation Type domain.

## Claim

Policy **means** a reusable Evaluation Type whose operative Substance prescribes a mechanism-neutral evaluation approach for a class of subjects or behaviors.

## Details

An evaluation may be realized by one or more mechanisms. This Type is not a test case, implementation, test suite, or one-to-one mechanism mapping, and it does not constrain an Atom to a particular tier.
