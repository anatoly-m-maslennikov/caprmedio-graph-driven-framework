## Summary

Define Requirement Type Entity Definition

## Claim

Entity Definition is a Requirement Type defining one primary Entity or dependent property: its meaning, structure and applicable constraints. It has required direct prose Claim; an optional R-only Formal claim complements that same scoped definition. Structural/property cardinalities and value formats belong in its formal part when applicable; other conditions stay in prose. Semantics and Details explain/support rather than add hidden operative requirements.

## Details

This is the general Type meaning, not the old Model-specific Graph Rule arrangement. It supersedes the older generic Definition Type. Advanced expression work remains a separate proposal.
