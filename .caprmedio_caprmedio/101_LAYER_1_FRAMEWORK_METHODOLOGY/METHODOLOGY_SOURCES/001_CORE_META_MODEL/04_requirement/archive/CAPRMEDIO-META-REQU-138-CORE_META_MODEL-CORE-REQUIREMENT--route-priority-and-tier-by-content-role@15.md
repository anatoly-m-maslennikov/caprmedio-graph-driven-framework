# Route priority and tier by Content role

Concern priority, Plan blocking, **and** Atom Local Tier **must** remain distinct coordinates; **every** Atom's Local Tier cardinality follows CA-R-155 regardless of its Content Role, **without** turning a Concern priority **or** a Plan Work Sequence Number into a Local Tier.
