# Summary

Define Entity/Continuant/Projection/Type: Direct Relation Registry

## Scope

Direct Relation Registry Projections.

## Claim

a Direct Relation Registry **means** an optional non-authoritative Projection of project-shared Relation Types, their defining source Claims, and selected Graph Rule declarations, traceable to those governing sources. It does not create a mandatory metadata registry or a graph-owned copy of a Relation Type.

## Details

CA-M-120 specifies optional compilation of this Projection. CA-R-806 supplies the minimal defining-Claim contract for Relation Types, CA-R-1246 supplies shared naming and any applicable Graph Rule constraints, and CA-R-1437 supplies source-authority distinction. These rules support the Projection but do not replace each Type's defining R Claim. This definition adds no mandatory registry workflow or independently authored authority.
