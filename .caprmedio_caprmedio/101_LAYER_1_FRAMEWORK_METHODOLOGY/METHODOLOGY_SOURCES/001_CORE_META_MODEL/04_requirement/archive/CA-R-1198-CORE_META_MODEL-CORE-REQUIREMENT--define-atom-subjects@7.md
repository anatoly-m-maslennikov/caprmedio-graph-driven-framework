# Define Atom Subjects

the Atom Subjects Property **means** the Atom Property that records direct GOVERNS **and** DEPENDS_ON references **to** Subjects, preserving their canonical target identities **without** an intermediate Subject object **or** an Entity **or** Reference Property for **every** link.
