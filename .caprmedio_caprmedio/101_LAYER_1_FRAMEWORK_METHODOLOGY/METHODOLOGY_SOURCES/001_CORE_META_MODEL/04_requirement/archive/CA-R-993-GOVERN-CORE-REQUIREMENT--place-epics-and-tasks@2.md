# Place Epics and Tasks

EVERY Epic Atom MUST use one folder carrier, EVERY contained Task Atom MUST use one file directly inside that folder or directly inside its `done` or `canceled` directory, and EVERY standalone Task Atom MUST use one file outside every Epic folder.
