# Register Project Layer authority and Delivery directory labels

GOVERNANCE reserves `FRAMEWORK_METHODOLOGY`, `FRAMEWORK_ENGINE`, and `OPERATOR_DOCUMENTATION` as both the ordered Project Layers' authority directory basenames under `.caprmedio` and their respective root Delivery directory basenames. Each authority-and-Delivery pair occupies different physical roots and represents one Scope Unit, not two Scope Units. Layer order remains a graph fact and is not encoded in these basenames.
