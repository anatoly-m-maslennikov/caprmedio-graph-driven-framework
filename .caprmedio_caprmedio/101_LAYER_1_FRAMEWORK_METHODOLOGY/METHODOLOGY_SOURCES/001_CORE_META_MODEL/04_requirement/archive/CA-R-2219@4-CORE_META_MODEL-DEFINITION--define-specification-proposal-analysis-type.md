## Summary

Define Specification Proposal Analysis Type

## Claim

Spec Proposal is an Analysis Type that presents a proposed specification for review before its adoption into governing RMED.

## Semantics

It records the proposed structure and supporting source definitions without becoming normative authority. Plans hold work and progress and link to the proposal. Spec Proposal is the new proposed name of the existing Specification Proposal Type, not an additional alias or a second Type.
