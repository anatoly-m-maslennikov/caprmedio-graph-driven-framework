## Summary

Define Delivery Type Decision

## Claim
Decision **means** a Delivery Type that records an engineering choice specific to its Local Scope Unit without automatically making that choice a rule for every child.

## Details

An Decision can be reused, but reuse does not make it an automatically inherited Policy. A named technology can occur in either Type; its name alone does not select Decision.

This Type does not constrain an Atom to a particular Tier. The PROGRAMMATIC-only allowed-Type restriction belongs to Project Configuration, not this reusable definition.
