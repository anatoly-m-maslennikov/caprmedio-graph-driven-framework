# Define General Local Tier

the Local Tier value General **means** the Local Tier of an Atom whose independently governable Claim specifies permitted semantic choices, relationships, derived sets, behavior, **or** validation criteria over already constituted Entities **without** selecting a concrete representation, realization procedure, **or** test specimen **and** **without** constituting their identity, purpose, authority ownership, fundamental separation, **or** semantic conservation boundary.
