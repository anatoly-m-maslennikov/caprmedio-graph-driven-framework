## Summary

Define Atom/Content Role: Evaluation/Type: Policy

## Claim

Eval Policy is a reusable Evaluation Type that prescribes a mechanism-neutral evaluation approach for a class of subjects or behaviors.

## Semantics

It can be realized by one or more mechanisms. It is not an Eval Case, implementation, test suite, or one-to-one mechanism mapping. Eval Policy replaces the shorter Type name Policy in the proposal only; it creates no Tier restriction.
