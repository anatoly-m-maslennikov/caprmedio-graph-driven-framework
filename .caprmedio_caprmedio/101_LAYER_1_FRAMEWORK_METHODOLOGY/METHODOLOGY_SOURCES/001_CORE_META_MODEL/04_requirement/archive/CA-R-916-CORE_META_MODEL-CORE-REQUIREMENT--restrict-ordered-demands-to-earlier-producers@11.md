# Restrict ordered Demands to earlier Producers

**if** a Demand Atom's Consumer Atom Scope Unit **and** Producer Claim Scope Scope Unit are ordered siblings, **then** its Producer Claim Scope Scope Unit **must** precede its Consumer Atom Scope Unit.
