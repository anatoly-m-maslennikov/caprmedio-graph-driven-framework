# Define Project Settings

the Term Project Settings **means** the authoritative Artifact containing Operator-selected initialization inputs for **`=1`** Project, including its Project Name **and** Project Atom prefix, needed **before** its first Atom **or** Implementation is created; it is **not** a Projection of existing Project Atoms **or** structure.
