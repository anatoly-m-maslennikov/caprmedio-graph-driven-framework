# Define CAPRMEDIO scope

CAPRMEDIO owns the concrete Project topology, immediate Project Layer scopes, relational Atoms whose exact endpoints cross immediate Project-child branches or include CAPRMEDIO, Project Adaptation, the Project Configuration Atom, and Atom authority adopted by the current Project. Relational Atoms bounded entirely within one descendant branch belong to their narrowest enabled common Structural scope. Generated Project Graph State Projections expose current topology and authority without owning either.
