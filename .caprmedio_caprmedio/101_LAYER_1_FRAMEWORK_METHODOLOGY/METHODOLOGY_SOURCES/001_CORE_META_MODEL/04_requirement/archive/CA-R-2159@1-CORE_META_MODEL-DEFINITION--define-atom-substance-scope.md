# Summary

Define Atom Substance Scope

## Scope

The optional applicability content of an Atom.

## Claim

Atom.Substance Scope means the content that states the exact applicability of
the Atom's Substance. It can restrict the cases, parts or conditions governed
by that Substance. It is a dependent property of the Atom, not another Scope
Unit or a reference assigning the Atom's local placement or Target Scope Unit.
