# Summary
Define Principle as Numeric Tier 0

## Scope

the numeric Tier value 0 and its initial display name Principle.

## Claim

Tier `0` has the initial display name Principle and denotes the highest initially named ordinary tier. Principle is admitted only for an Atom owned by the Project under CA-R-1443; this display-name rule does not impose a Content-Role or Type-to-Tier restriction.
