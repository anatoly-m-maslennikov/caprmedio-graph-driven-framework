## Summary

Define Atom Enabled Relations

## Claim scope

Kind-level enabled relation capabilities grouped under an Atom.

## Claim

Atom Enabled Relations is the non-scalar grouping property for kind-level enabled relation capabilities. Its child Contains states whether an Atom kind may contain other Atoms; default False and True permits but does not require children.
