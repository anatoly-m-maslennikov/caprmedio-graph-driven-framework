# Restrict Methodology Source Expansion to Core Permission

an Extension **or** Local Configuration **must** add Claims, Terms, allowed values, Types, Methods, Evaluations, Deliveries, Operations, activation decisions, compatibility decisions, **or** priority decisions **only** **where** one active CORE_META_MODEL Atom permits the addition **and** **must not** redefine, replace, shadow, weaken, delete, contradict, reinterpret, **or** mutate Core Meta-Model authority.
