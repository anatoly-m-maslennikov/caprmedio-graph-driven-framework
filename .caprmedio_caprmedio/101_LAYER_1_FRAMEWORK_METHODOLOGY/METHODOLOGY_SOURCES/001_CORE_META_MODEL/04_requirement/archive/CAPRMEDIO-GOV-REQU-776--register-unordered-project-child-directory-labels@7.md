# Register unordered Project-child directory labels

GOVERNANCE reserves `EXTENSIONS`, `RELEASES`, and `FIELD` as both the `.caprmedio` authority directory basenames and the root Delivery directory basenames for the corresponding unordered direct Project children. Each same-labelled authority-and-Delivery pair occupies different physical roots and represents one Scope Unit. No Structural or presentation ordinal is encoded in these basenames.
