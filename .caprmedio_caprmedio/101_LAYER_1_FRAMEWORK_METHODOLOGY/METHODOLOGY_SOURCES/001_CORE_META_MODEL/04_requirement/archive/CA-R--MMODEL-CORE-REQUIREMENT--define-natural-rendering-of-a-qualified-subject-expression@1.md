# Define Natural Rendering of a Qualified Subject Expression

a Natural Rendering of a qualified Subject Expression **means** the separator-free human-readable phrase that preserves the same named components **in** the same order **and** resolves **in** its context **to** the same canonical target with the same IS_BORNE_BY **and** IS_ALLOWED_VALUE_OF relations.
