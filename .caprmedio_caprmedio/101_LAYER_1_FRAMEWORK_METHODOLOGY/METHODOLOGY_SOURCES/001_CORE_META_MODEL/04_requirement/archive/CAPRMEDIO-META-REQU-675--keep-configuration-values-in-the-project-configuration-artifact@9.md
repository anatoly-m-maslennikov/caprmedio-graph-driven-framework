# Keep configuration values in the Project Configuration Artifact

The Project Configuration Artifact is the sole owner of current human-editable configuration values. Other Atoms own capability meanings, allowed configuration surfaces, constraints, **and** defaults but **must not** duplicate the project's current selected values as a second settings authority.
