# Keep Change and Implementation collections at Standard

an Atom Collection **or** structural decomposition view that groups CAPO **or** I content **must** resolve **to** Local Tier Standard, including Workflow **and** Objective groupings.

nesting expresses composition, **not** Core **or** General authority; an Objective's existing decomposition view remains the same Objective under CA-R-1533 rather than acquiring another identity.
