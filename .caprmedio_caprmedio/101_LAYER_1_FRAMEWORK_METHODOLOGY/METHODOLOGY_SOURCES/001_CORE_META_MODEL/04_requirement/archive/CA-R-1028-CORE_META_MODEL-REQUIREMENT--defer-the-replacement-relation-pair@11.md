# Defer the replacement relation pair

formal `replaced_by` **or** `replacement_of` relations **must not** be realized **until** separate authority admits that relation pair. **before** separate authority admits the relation pair, **every** replacement **or** absorption event **must** record explicit predecessor **and** successor Atom IDs **only** **in** the archival Journal event **and** **must not** create direct relation payloads **or** inverse views.
