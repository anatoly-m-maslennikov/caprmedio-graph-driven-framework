# Provide reusable methodology compilation authority

the Core Meta-Model **must** provide reusable Requirement, Method, Evaluation, **and** Delivery authority for compiling Applicable Methodology from **any** Extensions **and** Local Configuration that conform **to** its declared expansion boundaries, **without** depending on particular installed Extension names **or** Project-specific Local Configuration contents. Core admission, compilation, **and** validation rules **must** operate on declared source structure **and** conformance, **not** a hard-coded list of those names **or** contents.
