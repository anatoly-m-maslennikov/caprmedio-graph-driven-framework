# Summary

Define Atom/Content Role: Requirement/Type: Rule

## Scope

The Rule value in the qualified Requirement Type domain.

## Claim

Rule **means** the Requirement Type whose operative Substance states a condition, permission, prohibition or constraint on a governed structure, rather than defining what that structure is.

## Details

This registration does not retire or change existing Boundary or Constraint Requirement Types. Not every Requirement Atom of Type Rule is an Entity/Graph Rule; the governed Subject determines what the Rule concerns. Definitions and rules are distinct Requirement Type values.
