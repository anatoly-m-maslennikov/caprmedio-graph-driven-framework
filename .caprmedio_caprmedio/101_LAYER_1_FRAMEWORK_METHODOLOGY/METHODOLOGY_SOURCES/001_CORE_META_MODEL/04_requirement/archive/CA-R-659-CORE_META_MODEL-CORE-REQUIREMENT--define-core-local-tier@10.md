# Define Core Local Tier

the Local Tier value Core **means** the Local Tier of an Atom whose Claim establishes **or** preserves the identity, purpose, authority ownership, fundamental separation, **or** semantic conservation boundary of its governed Entity **without** selecting a concrete representation, realization procedure, **or** test specimen.
