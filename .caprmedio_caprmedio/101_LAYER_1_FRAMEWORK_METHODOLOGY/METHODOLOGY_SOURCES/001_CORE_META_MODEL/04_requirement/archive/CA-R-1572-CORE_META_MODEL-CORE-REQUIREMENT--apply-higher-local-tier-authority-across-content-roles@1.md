# Apply higher Local Tier authority across Content Roles

applicable higher Local Tier authority **must** govern lower-tier Atoms across **all** Content Roles (Concern, Analysis, Plan, Requirement, Method, Evaluation, Delivery, Implementation, Operations), **without** requiring matching Content Roles.

- Core Requirement foundations govern applicable General rules, including Method, Evaluation, **and** Delivery rules, **not** **only** General Requirements.
- General rules govern applicable Standard Atoms across **all** nine Content Roles, **not** **only** Standard Atoms matching the governing rule's role.
- applicability still follows the governed Scope **and** Subject; cross-role governance does **not** make **every** higher-tier Atom govern unrelated content **or** admit a forbidden role-tier combination.
