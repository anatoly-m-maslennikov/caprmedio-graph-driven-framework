# Summary
Define Standard as Numeric Tier 3

## Scope

the numeric Tier value 3 and its initial display name Standard within a Scope Unit.

## Claim

Tier `3` has the initial display name Standard and is the default lowest initially named Tier within a Scope Unit. Standard is a display/default convention only; it does not force a Content Role or Type. Higher numeric Tiers remain admissible when their Scope Unit range admits them.
