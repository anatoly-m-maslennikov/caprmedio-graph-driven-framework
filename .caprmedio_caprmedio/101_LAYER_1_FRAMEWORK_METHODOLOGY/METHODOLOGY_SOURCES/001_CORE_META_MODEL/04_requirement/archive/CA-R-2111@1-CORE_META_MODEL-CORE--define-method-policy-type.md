# Summary

Define Atom/Content Role: Method/Type: Policy

## Scope

The Policy value in the qualified Method Type domain.

## Claim

Policy **means** a reusable Method Type whose operative Substance prescribes a policy, approach, or method for a class of applications without itself specifying one concrete implementation choice.

## Details

This Type does not constrain an Atom to a particular tier. Existing specific Method Types remain valid where their governed meanings apply.
