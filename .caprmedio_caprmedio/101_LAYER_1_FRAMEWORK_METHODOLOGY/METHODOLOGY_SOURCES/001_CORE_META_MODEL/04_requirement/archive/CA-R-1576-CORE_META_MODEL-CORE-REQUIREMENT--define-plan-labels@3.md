# Define Plan Labels

`Atom/Content Role: Plan/Type: Plan/Label` **means** the Label Property borne by a Plan Atom under CA-R-1594, with examples (Version, Objective, Epic, Sub-epic, Mega-epic, Task, Subtask); these examples are navigation Labels, **not** an authoring Subtype registry.
