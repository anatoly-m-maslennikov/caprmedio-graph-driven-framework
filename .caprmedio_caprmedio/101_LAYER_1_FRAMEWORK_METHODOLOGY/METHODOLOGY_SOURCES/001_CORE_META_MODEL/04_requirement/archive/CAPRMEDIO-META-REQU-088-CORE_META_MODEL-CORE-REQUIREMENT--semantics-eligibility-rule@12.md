# SEMANTICS eligibility rule

A rule belongs **in** SEMANTICS **only** **when** it remains true as downstream languages, tools, hosts, providers, **and** repository layouts change, governs multiple layers **or** defines a boundary between layers, **and** can be stated **without** importing downstream implementation concepts.
