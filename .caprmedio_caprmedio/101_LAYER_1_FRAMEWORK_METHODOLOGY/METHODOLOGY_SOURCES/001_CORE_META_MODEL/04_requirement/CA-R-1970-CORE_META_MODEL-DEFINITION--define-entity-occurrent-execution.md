# Summary

Define Entity/Occurrent/Execution

## Scope

Executions as Occurrents.

## Claim

an Execution **means** the actual performance of work. it is distinct from its reusable definition **and** from records describing what happened.

## Details

Candidate #6 distinguishes definitions, actual runs and records. CA-R-1510 defines Workflow Run and CA-R-1511 defines Step Run as narrower actual executions; neither defines Execution generally.
