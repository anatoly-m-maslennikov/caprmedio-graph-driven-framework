# Summary
Permit reused Terms **in** qualified value domains

## Scope
a Term naming an allowed value **in** multiple qualified Property contexts.

## Claim

a Term **may** name an allowed value **in** multiple qualified Property contexts **when** governing authority admits that value separately **in** **every** such context; admission **in** one context does **not** admit the value **in** another.
