## Summary

Define Summary as an Atom-owned, non-authoritative navigation property

## Claim scope

the Summary Property of an Atom.

## Claim

a Summary **means** a short, non-authoritative navigation Property of **`=1`** Atom, derived from the finalized primary contribution registered for its Content Role, read within its applicability. it belongs **to** that Atom **without** independent identity, lifecycle, **or** authority. It faithfully covers the Atom's whole meaning as expressed by that primary contribution within its applicability, rather than merely naming a topic. Supporting details need not all be listed in the Summary.

## Details

for ordinary RMED, the source is Claim read within Scope, **not** Scope alone; for Analysis, Question; for Concern, Concern; for Plan, Objective; for Operations, Operation. Summary is written last but remains displayed first. Analysis TLDR summarizes its Results; it is **not** the Atom Summary **and** does **not** replace Question as the Summary source.
