## Summary

Define a Scope Definition Requirement for one Target Scope Unit

## Claim scope

Scope Definition Requirement Atoms.

## Claim

A Scope Definition is an Atom of Content Role Requirement and Type Scope Definition. Its Claim defines a coherent Scope for exactly one Target Scope Unit: the unit's purpose, responsibilities, expected results and boundaries. Prefer one coherent Scope Definition for each resolved Target Scope Unit rather than one per former Goal. Its declaring owner and Target Scope Unit remain explicit; ordinary ownership is by a Local Scope Unit, while the proposed Project-targeted Operator Actor exception is addressed separately.

## Details

The previous definition required one desired result for one non-Project Target Scope Unit and distinguished Project Goal and its owner exception. Preserve specific outcome constraints separately where needed; do not create a separate Scope Definition for each former desired result. The paired Project exception is proposal replacement-ca-r-2152. Neither the new Type nor its ownership rules are admitted by this trial.
