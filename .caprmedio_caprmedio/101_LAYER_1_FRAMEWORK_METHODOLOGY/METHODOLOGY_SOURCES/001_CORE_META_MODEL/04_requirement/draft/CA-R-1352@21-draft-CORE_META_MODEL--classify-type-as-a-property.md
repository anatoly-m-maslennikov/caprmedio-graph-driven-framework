## Details

### Withdrawn preparation

This preparation is retained only as historical evidence and excluded from
the active register: its Claim classifies the lexical Term Type as a
Property, conflating a Term with the Properties named using it. The latest
Operator decision does retain Type as a Property, including classification
use; that meaning is preserved in the selected R1284 successor. Withdrawal
here rejects the Term/entity conflation, not the Property meaning. Current
R1352 is unchanged; its future disposition requires coordinated adoption
and preservation of its applicable meaning.
