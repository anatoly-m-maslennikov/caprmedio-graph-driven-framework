# Summary

Define Entity/Occurrent

## Scope

actual occurrences.

## Claim

an Occurrent **means** an actual occurrence, such as an Event, Execution or Session. a stored record describes the occurrence; it is **not** the occurrence itself.

## Details

CA-R-1510 and CA-R-1511 define particular Run kinds; CA-R-1745 distinguishes Journal records from events. This definition adds no Run or Session lifecycle.
