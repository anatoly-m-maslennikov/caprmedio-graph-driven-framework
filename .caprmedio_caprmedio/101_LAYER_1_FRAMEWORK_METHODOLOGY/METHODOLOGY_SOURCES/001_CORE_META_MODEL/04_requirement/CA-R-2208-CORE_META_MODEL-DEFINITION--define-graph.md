# Summary

Define Graph

## Scope

Graph in the Subject model.

## Claim

Graph is the Subject grouping for Node, Relation and Rule: the things or topics represented, their typed connections and the constraints on Nodes, Relations and their properties.

## Semantics

These branches describe the graph model. A Carrier represents stored content; being represented by a graph node does not require classifying a Carrier as the thing it carries.
