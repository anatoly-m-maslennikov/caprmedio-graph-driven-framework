# Propose source corrections

Propose Source Corrections **means** the reusable Action that prepares an explicit resolution proposal for an identified conflict **in** one exact selected source frontier. the proposal **must** identify the affected source authority, the exact proposed correction **or** permitted resolution decision, the intended outcome, **and** relevant effects **and** uncertainty. **any** needed correction **must** target the owning source authority through its governed change workflow, **not** a derived copy; a proposal does **not** authorize **or** perform the change. **if** no sufficiently supported proposal fits the applicable authority **and** confidence constraints, the Action **must** report that limitation for Operator escalation rather than invent a resolution.
