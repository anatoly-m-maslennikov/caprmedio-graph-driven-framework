# Run implementation Evaluations

Implementation Evaluation **means** the Action that executes selected applicable Evaluations against the candidate Implementation **when** their execution prerequisites are available **and** returns the actual results for that candidate. preserve failed, blocked, **and** unevaluated outcomes as such; preparation of an Evaluation **must not** substitute for its execution. the returned results **must not** represent a different candidate **or** earlier governing baseline as the evaluated current one.
