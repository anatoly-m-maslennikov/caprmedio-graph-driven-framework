# Support portable execution platforms

Canonical CAPRMEDIO Tools **and** Skills support macOS, Linux, Windows, **and** WSL, while reusable platform-specific behavior is isolated **in** an explicit Adapter **or** Extension **and** project-specific behavior **in** a Project Adaptation.
