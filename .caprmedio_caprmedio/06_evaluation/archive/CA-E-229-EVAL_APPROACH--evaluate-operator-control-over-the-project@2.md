# Evaluate Operator control over the project

## Claim checked

The declared Operators collectively control every governed project part, and every material project change is observable, steerable, interruptible, and recoverable by them under their current authority.

## Applicable conditions

Apply to each admitted material project-change class and after a material change to project authority or control mechanisms.

## Check

Enumerate every governed project part and every admitted material project-change class. For each part, demonstrate collective Operator inspection and direction. For each change class, demonstrate an Operator-visible state, an admissible steering action, an interruption boundary, and a recovery path.

## Acceptance

Pass only when every governed project part is collectively inspectable and directable and every admitted material change class has demonstrated observability, steerability, interruptibility, and recoverability under current Operator authority.

## Failure

Fail and report every uncontrolled project part or change class missing any required control property.
