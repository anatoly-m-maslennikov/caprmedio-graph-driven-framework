## Summary

Govern the installed Extension lifecycle

## Claim

the built-in Extension lifecycle **must** govern installation, uninstallation, update **to** a later exact version, **and** downgrade **to** an earlier exact version.

Installed Extensions use the existing installed-Extensions Scope Units. This preserves the lifecycle capability without introducing a separate Extension Object or an application-binding system. C611 tracks the remaining representation choice.
