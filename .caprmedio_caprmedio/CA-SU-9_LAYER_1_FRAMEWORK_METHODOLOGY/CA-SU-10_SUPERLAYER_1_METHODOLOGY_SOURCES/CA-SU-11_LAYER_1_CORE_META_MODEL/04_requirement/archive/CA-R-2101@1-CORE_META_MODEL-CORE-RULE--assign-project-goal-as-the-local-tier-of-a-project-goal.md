# Summary

Assign Project Goal as the Local Tier of a Project Goal

## Scope

Project Goal Atoms.

## Claim

Every Project Goal Atom **must** have exactly one Local Tier, whose value is `Project Goal`. A Project Goal's Local Tier is not omitted; it is not one of Principle, Core, General, or Standard. This Rule assigns the Project Goal Local Tier value and does not impose arbitrary Type-to-tier restrictions.
