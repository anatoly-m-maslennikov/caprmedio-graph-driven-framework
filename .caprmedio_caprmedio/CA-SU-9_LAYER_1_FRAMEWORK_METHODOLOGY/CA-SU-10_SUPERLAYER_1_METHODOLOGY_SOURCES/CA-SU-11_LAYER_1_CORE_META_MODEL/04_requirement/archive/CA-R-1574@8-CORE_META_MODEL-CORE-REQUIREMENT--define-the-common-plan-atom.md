# Summary

Define the common Plan Atom

## Scope

Plan Atoms with Type Plan.

## Claim

a Plan Atom **means** an Atom with Content Role Plan **and** Type Plan whose **`=1`** Claim states bounded intended work **or** an intended outcome; its Label does **not** select a different authoring model.
