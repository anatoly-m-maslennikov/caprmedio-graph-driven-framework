# Define Subject Expression

a Subject Expression **means** a reference **to** **`=1`** Entity, Action, **or** Process formed from Term references **and** registered relation syntax. **every** named component, including the initial target name, Property names, **and** named allowed values, references a Term; `/` **and** `:` are syntax, **not** Terms. the expression identifies the target, **not** the Atom's Subject Relation **to** it.
