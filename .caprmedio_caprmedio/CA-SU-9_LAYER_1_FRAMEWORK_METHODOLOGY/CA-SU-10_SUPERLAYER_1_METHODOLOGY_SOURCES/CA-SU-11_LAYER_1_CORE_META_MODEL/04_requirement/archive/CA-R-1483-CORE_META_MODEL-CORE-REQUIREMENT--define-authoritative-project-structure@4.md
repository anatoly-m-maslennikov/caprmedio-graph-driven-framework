# Define authoritative Project Structure

Project Structure **means** the authoritative non-Atom Artifact containing a Project's accepted Scope Unit declarations. it is the single source for those structural facts, **not** a Projection, a Goal Atom, **or** a duplicate of filesystem observations; its Carrier is governed separately by Delivery authority.
