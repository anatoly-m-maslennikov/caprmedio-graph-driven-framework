# Review external Analysis before project adoption

Every admitted external Analysis is reviewed by one internal Analysis before it can produce project-owned Concern, Plan, Requirement, Method, Evaluation, or Delivery Atoms. The external Analysis remains authoritative only for what its external source reported; the internal Analysis owns the project's interpretation and dispositions, and each resulting Atom owns its independently accepted meaning.
