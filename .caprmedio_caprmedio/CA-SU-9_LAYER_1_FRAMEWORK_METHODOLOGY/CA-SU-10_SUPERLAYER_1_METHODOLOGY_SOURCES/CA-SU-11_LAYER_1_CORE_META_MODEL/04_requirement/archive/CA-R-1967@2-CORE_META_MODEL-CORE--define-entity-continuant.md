# Summary

Define Entity/Continuant

## Scope

Continuants.

## Claim

a Continuant **means** an Entity that persists as an identifiable thing, rather than an actual occurrence unfolding in time.

## Details

Candidate #6 places Object, Project, Actor, History, Projection, Selection and Term under Continuant. CA-R-1248 defines Entity but does not define this distinction. Continuance does not make content immutable or make every Continuant a source of current authority.
