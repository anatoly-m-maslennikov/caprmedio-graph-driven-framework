# Select Authority Modes through Framework Instance Settings

the Authority Mode for a Project **or** Scope Unit **must** be selected using the effective framework-instance default **and** optional explicit target-specific overrides; the permitted values are `strict` **and** `casual`, **and** neither changes the authority of active Atoms.
