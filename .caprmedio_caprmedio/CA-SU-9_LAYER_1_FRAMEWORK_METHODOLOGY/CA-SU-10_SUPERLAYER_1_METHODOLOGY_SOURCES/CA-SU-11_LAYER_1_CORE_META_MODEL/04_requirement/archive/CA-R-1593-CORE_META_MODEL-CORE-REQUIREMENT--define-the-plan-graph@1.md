# Define the Plan Graph

the Plan Graph **means** a Projection whose nodes reference authoritative Plan Atoms **and** whose graph-owned Relations represent work decomposition **and** blocking. folder placement **and** explicit Plan relation declarations remain the sources of those facts; the Projection **must not** become another authoritative declaration.
