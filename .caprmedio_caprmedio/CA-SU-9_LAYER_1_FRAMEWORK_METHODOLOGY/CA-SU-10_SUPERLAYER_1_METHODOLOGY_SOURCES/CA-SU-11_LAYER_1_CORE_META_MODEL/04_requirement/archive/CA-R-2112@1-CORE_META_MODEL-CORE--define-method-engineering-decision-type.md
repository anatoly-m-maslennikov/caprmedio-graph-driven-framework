# Summary

Define Atom/Content Role: Method/Type: Engineering Decision

## Scope

The Engineering Decision value in the qualified Method Type domain.

## Claim

Engineering Decision **means** a Method Type that records one concrete engineering choice for an explicit realization target.

## Details

This Type does not constrain an Atom to a particular tier. The choice remains distinct from reusable policies and methods.
