# Encode project scope authority modes in the Scope Unit Graph

the generated Project Scope Unit Graph Projections **must** encode the effective `authority_mode` selected by the Project Settings Artifact for the Project root **and** **every** current Scope Unit **without** making the Projection an authority for those modes.
