# Summary

Define Summary as an Atom Property

## Claim

a Summary **means** a short, non-authoritative navigation Property of **`=1`** Atom, derived from the finalized first Content-Role-specific body block registered by its Delivery authority. it belongs **to** that Atom **without** independent identity, lifecycle, **or** authority.

## Details

for RMED, the source is Claim; for Analysis, Question; for Concern, Concern; for Plan, Objective; for Operations, Operation. Summary is written last but remains displayed first. Analysis TLDR summarizes its Results; it is **not** the Atom Summary **and** does **not** replace Question as the Summary source.
