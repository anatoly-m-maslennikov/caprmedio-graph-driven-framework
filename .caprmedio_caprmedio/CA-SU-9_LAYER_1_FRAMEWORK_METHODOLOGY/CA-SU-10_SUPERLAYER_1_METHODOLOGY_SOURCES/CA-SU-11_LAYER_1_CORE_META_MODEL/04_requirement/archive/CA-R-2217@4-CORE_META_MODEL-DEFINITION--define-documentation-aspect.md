## Summary

Define Documentation Aspect

## Claim scope

Documentation Aspect in the Subject model.

## Claim

The Documentation Aspect addresses how explanatory, instructional and reference material is organized and written.

## Semantics

Implementation/Documentation names actual material. This Aspect names topics governing that material; it does not duplicate the documents or introduce document instances.
