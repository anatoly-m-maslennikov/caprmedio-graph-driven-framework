# Encode path-token case by semantic role

In every Project-owned Atom filename, `<PROJECT_PREFIX>`, `<CONTENT_ROLE_LETTER>`, `<CURRENT_SCOPE>`, `<LOCAL_TIER>`, `<ATOM_TYPE>`, and `<TARGET_SCOPE>` use uppercase ASCII tokens; underscores join words inside a token. `<SUMMARY_SLUG>` uses lowercase ASCII kebab-case and `<EXT>` uses lowercase ASCII letters or digits. Each registered Scope Unit full name is one uppercase `SNAKE_CASE` directory token and a Scope Unit's directory basename is that token unchanged. Numbers and separators carry no case.

Canonical Scope Unit directory basenames include `GOVERNANCE`, `FRAMEWORK_METHODOLOGY`, and `EXTENSIONS`. Canonical Atom filenames include `CA-R-004-PRINCIPLE-REQUIREMENT--provide-operator-control-over-the-caprmedio-instance.md`, `CA-R-888-GOV-CORE-REQUIREMENT--require-portable-automation-safe-project-path-names.md`, and `CA-R-123-FR_MTHD-DEMAND_FOR-FR_ENGN--provide-support-for-full-methodology.md`. Lifecycle and organizational directory names remain lowercase.
