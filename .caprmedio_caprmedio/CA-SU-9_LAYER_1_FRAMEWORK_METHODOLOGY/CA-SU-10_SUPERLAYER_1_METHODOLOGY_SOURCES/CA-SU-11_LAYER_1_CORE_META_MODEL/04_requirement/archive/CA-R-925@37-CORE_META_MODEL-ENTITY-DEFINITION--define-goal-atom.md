## Summary
Define Goal Atom

## Claim scope

Goal Atoms.

## Claim

a Goal Atom **means** a Relational Atom with Content Role Requirement **and** Type Goal whose Claim states one desired result for **`=1`** non-Project Target Scope Unit and whose owner is that Target Scope Unit’s immediate parent Scope Unit. The Goal states the parent’s external expectation for the child; local foundational commitments are expressed by Tier 0 Atoms owned by the child. A Goal targeting the Project uses the distinct Type Project Goal; its Operator-owner exception does not apply to ordinary Goal Atoms.
