Define Requirement Type Term Definition

## Claim

Term Definition is the reserved Requirement Type for defining a Term’s meaning. It is distinct from Entity Definition, which defines an Entity or property structure and constraints. The Term Definition Type has the shared Requirement Claim contract; this Type declaration does not create actual Term Definition Atoms.
