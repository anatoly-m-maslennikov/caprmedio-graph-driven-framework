# Summary

Define Documentation

## Claim

Documentation **means** the other descriptive, explanatory or reference Implementation content about the project and framework, for users and LLMs.

## Semantics

Runbooks, how-tos and instructions belong to Prompts. Documentation provides the other project and framework information. Being read by an LLM does not by itself make that content a Prompt.
