# Resolve Project and Framework Settings before derived structure

**to** operate a Project, resolve its Project Settings **and** project-owned Framework Instance Settings through their registered authoritative TOML Carriers **before** using derived Project Structure; **do not** require an existing Project Atom **or** Implementation to resolve initialization inputs, substitute a Projection for either Settings Artifact, **or** read another Project's instance settings.
