# Retirement review list

Historical pre-adoption review list. The 291 former Node Definition carriers are now archived. The applied dispositions are in [publication-receipt.json](publication-receipt.json). Continuant and Occurrent remain through [replacement Declarations](retained-concept-replacements.json).

The previous plan mixed two actions: replacing an old Definition with a Declaration, and removing a concept. A carrier retirement is not proof that its concept disappears. Continuant and Occurrent are retained by the latest Operator correction. The corrected inventory was applied; the candidate labels below preserve the earlier review state.

## Primary concepts omitted by the earlier inventory

These are omission candidates from the earlier plan, not a final list of removed concepts. Actor kinds, document components and execution concepts need explicit representation decisions before they are treated as deleted.

- **Structural and grouping concepts:** Object, Governing Objects, Governing Configuration, Structural Unit, History, Release.
- **Actor kinds:** Operator, AI Agent.
- **Events and execution:** Event, Execution, Workflow Run, Step Run, Action Run, Runtime, Session, Container Run, Process Run.
- **Implementation and documents:** Module, Code Unit, Function, Class, Prompt, Asset, Configuration, Schema, Template, Test Fixture, Documentation, Document, Section, Paragraph, Sentence, List, Table, Code Block, Diagram, Eval Package, Runtime Package.

Entity is the generic root previously selected for retirement. Object remains a registered Term for a Node instance even if its old primary-kind Definition is replaced or removed.

Atom, Actor, Scope Unit, Project, Aspect, Package, Projection, Journal, Event Record and Operations retain Declaration candidates. Selection changes toward Named Selection; that is a representation change, not simple deletion.
