# Register Boundary Requirement Type

GOVERNANCE registers `boundary` as the internal Requirement Type for one explicit current limit on the applicability, support, availability, or ownership claimed by a project. A Boundary states where current project authority stops; it is not a desired outcome expressed by the default `requirement` Type, an externally imposed `constraint`, a cross-scope `demand_for`, or a selected realization Method. Its canonical class short name is `boundary`.
