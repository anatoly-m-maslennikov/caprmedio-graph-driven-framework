# Summary

Register Type Values for Delivery Atoms

## Scope

`Atom/Content Role: Delivery/Type` values.

## Claim

Policy, Engineering Decision, Release Definition, **and** Environment Definition **must** be registered as internal values of `Atom/Content Role: Delivery/Type`.

## Details

Policy and Engineering Decision are defined by CA-R-2113 and CA-R-2114. Existing specific Delivery Types remain valid where their meanings apply; registration does not constrain a Type value to a particular tier.
