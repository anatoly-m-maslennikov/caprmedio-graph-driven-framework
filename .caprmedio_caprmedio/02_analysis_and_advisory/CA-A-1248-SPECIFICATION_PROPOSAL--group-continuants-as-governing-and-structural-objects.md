# Summary

Group Continuants as governing and structural objects

## Decision

The latest Continuant tree groups Atom and Governing Configuration under Governing Objects; Project under Structural Unit with contained Scope Units; Journal under History with required Event Records; and Code, Documentation, Prompts and Resources as Implementation parts. Actor, Selection and Term retain their stated classifications. Projection remains a direct Continuant.

Use actual specialization for the Governing Objects and Structural Unit classifications. Use containment for Project > Scope Unit, recursive Scope Unit parts and Implementation parts. Classify contained kinds by references where needed: such a reference does not create independent existence outside the required container. Scope Unit is a Structural Unit even though its declaration is under Project. Existing Role/Type authority and Operator-owned Project Goal rules remain unchanged; Analysis gains no normative authority merely from the Governing Objects classification.

No new numeric structural level, generic Status, shared-ID property or renamed ownership field is implied by these groups. Project remains the existing root ownership context under its applicable contracts. Detailed property-typing alignment belongs in the migration tasks, not a silent side effect of drawing the tree.
