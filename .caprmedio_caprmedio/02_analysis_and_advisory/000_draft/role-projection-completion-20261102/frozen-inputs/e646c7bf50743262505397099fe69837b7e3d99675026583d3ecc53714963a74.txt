## Summary

Register Core Analysis Status Values

## Claim scope

the default Status value domain of Analysis & Advisory Atoms with Type Analysis Report or Rationale.

## Claim

the Core Analysis & Advisory Status model **must** inherit the allowed values of Atom.Status and add Done. That Content Role Status model applies to Analysis & Advisory Atoms with Type Analysis Report or Rationale. An admitted Extension or Project Configuration **may** add values under the applicable complete Content Role and Type path; it **must not** remove inherited values.

## Details

this Status belongs to the Analysis & Advisory Atom itself. It does **not** define a Status transition, carrier placement, setting, or a Workflow, Step, or Action Run outcome, receipt, retry state, result, or completion state. CA-R-1727@30 defines the meanings of Draft and Done for Analysis and the meaning of its archival.
