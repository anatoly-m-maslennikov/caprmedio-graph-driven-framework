## Summary

Permit confidence-threshold defaults and overrides

## Claim

### Prose Claim


the source of a Confidence Threshold value.


For a decision executing a Plan, the AI Agent Confidence Threshold **must** resolve from the current Plan's explicit Header value, otherwise the nearest explicit value on an enclosing Plan reached recursively through `IS_CONTAINED_BY`, otherwise the required `Project.Settings.AI Agent Confidence Threshold`. An enclosing Plan does not need a Hub Label.

For a decision outside Plan execution, resolve the applicable Confidence Threshold from direct Operator input within its stated context, otherwise the applicable Project.Settings default for that threshold. Resolve each threshold independently. An omitted Plan value is not copied locally; an invalid or ambiguous reached source requires Operator disposition without silent fallback.
