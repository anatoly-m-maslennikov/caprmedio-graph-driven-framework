## Summary

Permit confidence-threshold defaults and overrides

## Claim

### Prose Claim


the source of a Confidence Threshold value.


For a decision executing a Plan, the AI Agent Confidence Threshold **must** resolve from the current Plan's explicit Header value, otherwise the nearest explicit value on an enclosing Plan reached recursively through `IS_CONTAINED_BY`, otherwise the required `Project.Settings.AI Agent Confidence Threshold`. An enclosing Plan does not need a Hub Label.

For any other Confidence Threshold, and for a decision outside Plan execution, retain the applicable order of direct Operator input in its stated context, an explicit value on an applicable current Plan, the nearest enclosing Hub Plan with an explicit applicable value, and the applicable Project.Settings default for that threshold. Do not infer another Plan Property or equate different thresholds. Resolve each threshold independently. An omitted Plan value is not copied locally; an invalid or ambiguous reached source requires Operator disposition without silent fallback.
