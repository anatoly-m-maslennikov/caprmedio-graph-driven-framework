## Summary

Define Configuration selection and precedence

## Claim

### Prose Claim


Framework Instance Settings Artifact selection and composition of available capabilities.


the Framework Instance Settings Artifact **may** select, combine, parameterize, activate, **or** disable available capabilities **and** **must** resolve composition precedence explicitly **without** changing **any** selected capability's governed meaning. Availability does **not** by itself establish activation; retained configuration values do **not** activate a capability unless its governing Settings explicitly select it.
