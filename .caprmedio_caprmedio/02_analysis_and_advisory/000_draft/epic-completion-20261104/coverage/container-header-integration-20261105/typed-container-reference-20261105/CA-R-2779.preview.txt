## Summary

Declare Atom.Header.Container

## Claim

### Formal Claim

```CFEL
# model
Atom.Header.Container{::1} :: []{::0};

Atom.Header.Container.*[in(atom,scope_unit)]{::1}

# instances
Atom//$atom;
$atom.Header.Container{::1}
```

### Prose Claim

Header.Container identifies the Atom's immediate Container.

For ordinary Atom containment, Header.Container contains exactly one key: `atom` selects a containing Atom by its base Atom ID, or `scope_unit` selects a Scope Unit by its stable ID. A base Atom ID selects Current by default.

The literal bootstrap value `world` produces zero containment links.
Header.Container is the sole stored Atom-containment value.
