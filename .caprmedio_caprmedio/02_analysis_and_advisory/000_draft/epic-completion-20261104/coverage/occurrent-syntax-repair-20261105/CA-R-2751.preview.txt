## Summary

Declare Step Run

## Claim

### Formal Claim

```CFEL
# model
Step Run ((NARROWER_THAN)) Execution;

Step Run >| (Container == yes);

# instances
$run[<Step Run>] {::1}((IS_EXECUTION_OF)) $definition[<Step>];

$step_run[<Step Run>] {::1}((IS_CONTAINED_BY)) $container[<Workflow Run> OR <Step Run>];

$step_parent[<Step Run>] {::0+}((CONTAINS)) $nested_step[<Step Run>];

$action_parent[<Step Run>] {::0+}((CONTAINS)) $action_run[<Action Run>]
```

## Semantics

A Step Run is an actual execution of one Step within a Workflow Run.
