the current Project Scope Unit Graph is represented by generated Implementation Projections derived from the exact Project Settings Artifact revision, admitted `project_scope_unit_graph` **or** `project_graph_state` contributions, current graph structure, **and** applicable Journal records. these Projections expose current derived state **without** establishing, selecting, **or** modifying Project authority.
