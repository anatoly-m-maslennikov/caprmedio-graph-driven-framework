# Implement Requirements

Requirement Implementation **means** the Action that realizes selected applicable Requirements whose prerequisites are satisfied, applying **all** Methods governing that work within the applicable Delivery boundaries. return the candidate Implementation **and** the actual result of the selected work. an unresolved Method conflict requires an authority disposition; Atom ID **must not** select the winning Method.
