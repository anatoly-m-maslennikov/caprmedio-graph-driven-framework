# Implement Evaluations

Evaluation Implementation **means** the Action that prepares the implementation of selected applicable Evaluations whose prerequisites are satisfied, applying **all** Methods governing that work within the applicable Delivery boundaries. reuse sufficient existing Evaluation implementations **when** the selected mode permits reuse. return the prepared **or** reused implementation **and** the actual result of that work; preparation **must not** be reported as Evaluation execution **or** as proof that the candidate passes.
