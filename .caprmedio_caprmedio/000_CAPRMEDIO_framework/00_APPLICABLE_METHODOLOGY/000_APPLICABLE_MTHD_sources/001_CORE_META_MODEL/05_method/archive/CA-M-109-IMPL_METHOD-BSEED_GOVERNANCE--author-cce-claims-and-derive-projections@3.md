# Author CCE Claims and derive Projections

Seal one active or draft Atom and its current direct-relation sources. Identify the Atom's Content role, role-specific atomic unit, current ordinary statement, any formula, and every identity, bearer, modality, polarity, predicate, participant, quantity, condition, Applicability, acceptance, and failure distinction.

When ordinary text and a formula agree, preserve their shared complete meaning. When they differ, select the interpretation best supported by current authority, direct relations, role atomicity, completeness, and testability. Stop and request Operator disposition when semantic-resolution confidence is below `confidence.semantic_resolution_threshold_percent`. Do not alter independently decidable Atoms while one Atom awaits disposition.

Select the admitted CCE version and the one role-compatible statement form. Resolve every content token through the applicable active vocabulary registry, plus explicitly related candidate entries for a draft. Fill every required typed slot, serialize the resulting representation canonically, parse that serialization, and accept it only when the parsed representation equals the authored representation and every version, vocabulary, predicate, type, cardinality, scope, and ordering check passes.

Derive the CCE Summary, filename Summary slug, H1, and any requested Translation from the accepted representation. Compose the canonical filename from the stable Atom ID or visible draft absence marker, non-Project current Scope Unit when applicable, explicit `PRINCIPLE` or `CORE` marker when applicable, Atom Type, Type-required target Scope Unit when applicable, derived Summary slug, and extension. Parse the composed filename back into the same facts before renaming the Carrier. Update draft locators or stable-identity references as applicable. Remove an alternative formula only after the CCE Claim and all derived Projections pass evaluation. Preserve draft lifecycle and absence of Atom ID unless the Operator separately accepts promotion.
