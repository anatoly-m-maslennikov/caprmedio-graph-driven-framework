# Define Core Local Tier

the Local Tier value Core **means** the foundational Spec tier that establishes the model premises **and** boundaries governing **all** Atoms at greater Global Tiers **in** the Scope Unit under CA-R-1573, including General **and** Standard Atoms across **all** Content Roles.

these foundations establish identity, purpose, authority ownership, fundamental separation, **or** conservation boundaries; they are **not** concrete CAPO **or** I content **and** do **not** gain their tier from the role of the content they specify.
