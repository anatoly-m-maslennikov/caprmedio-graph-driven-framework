# Project current structure without creating authority

Project Structure **means** the read-only Project Scope Unit Graph Projection of all Project Atoms **and** actual Scope Unit Directory Carriers, bound to applicable Settings **and** source revisions; it records what exists **without** establishing **or** changing authority. a Scope Unit Directory Carrier **must** remain visible **when** it has no active accepted Goal, with that gap reported separately; drafts **and** archived Atoms provide evidence **without** becoming active authority.
