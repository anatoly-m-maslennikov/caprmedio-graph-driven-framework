# Summary

Use Realization Graphs only as Evaluation evidence

## Claim

**when** an Evaluation uses a Realization Graph, it **must** treat that graph as evidence checked against separately identified governing Claims, **not** as the authority defining the expected result.

this boundary applies **to** Evaluation use; it does **not** prohibit using the same non-authoritative Projection for reverse engineering, analysis, **or** preparation of proposed RMED.
