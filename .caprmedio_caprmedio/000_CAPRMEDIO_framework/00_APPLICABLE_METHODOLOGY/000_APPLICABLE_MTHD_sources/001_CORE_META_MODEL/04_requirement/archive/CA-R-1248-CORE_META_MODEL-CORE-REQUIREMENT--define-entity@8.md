# Define Entity

an Entity **means** one independently identified **or** bearer-qualified object admitted by an authoritative source as a possible node **in** **`>=1`** CAPRMEDIO Graph, excluding Action **and** Workflow identities. referencing an Action **or** Workflow from a graph does **not** classify it as an Entity **or** create an Entity duplicate of it.
