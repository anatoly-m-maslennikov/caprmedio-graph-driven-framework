# Define Operations Content Role

Operations (Ops, identity letter O) **means** the Content Role of an Atom Claim that defines reusable operational Action **or** Process behavior **or** an Actor participation/authorization policy. the reusable definition, a particular execution, **and** the Journal Records carrying its execution evidence **and** state changes are distinct.
