# Define Spec Content Roles

Spec Content Roles **means** the set (Requirement, Method, Evaluation, Delivery) that specifies Implementation; reusable operational Action **and** Process definitions, Actor participation/authorization policies, **and** actual executions are **not** Spec contents. a meta-model Claim that defines these distinctions remains eligible for Requirement according **to** its primary contribution.
