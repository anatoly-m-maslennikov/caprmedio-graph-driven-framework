# Use Canonical Qualified Entity Names in Every Atom

**every** qualified Entity reference **in** Atom frontmatter **or** Atom content **must** use its canonical Subject Expression **and must** retain each required `/` **and** `:` separator; a Natural Rendering **must not** substitute **for** that canonical expression **in** an Atom.
