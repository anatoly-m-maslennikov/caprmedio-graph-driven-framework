# Define Operations Content Role

Operations (identity letter O) **means** the Content Role of an Atom Claim that establishes the operational model, reusable rules governing that model, **or** specific reusable Action, Workflow, **or** Actor participation/authorization behavior.

- the operational vertical contains its own foundations, rules, **and** specific definitions under CA-O-068 **and** CA-O-069; it is **not** a realization of RMED.
- RMED specifies Implementation, including an executor **or** Tool that interprets **or** realizes Operations definitions. that Implementation specification does **not** replace the operational definition **or** make the chosen production Workflow part of its Spec.
- a reusable definition, a particular execution, **and** the Journal Records carrying execution evidence **and** state changes remain distinct.
