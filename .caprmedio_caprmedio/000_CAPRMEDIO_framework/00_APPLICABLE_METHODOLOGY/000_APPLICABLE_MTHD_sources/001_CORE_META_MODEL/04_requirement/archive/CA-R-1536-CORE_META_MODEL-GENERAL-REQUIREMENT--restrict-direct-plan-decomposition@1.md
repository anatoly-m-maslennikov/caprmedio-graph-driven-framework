# Restrict Direct Plan Decomposition

an Objective Atom Work Decomposition View **may** directly contain **only** Objective Atoms **or** Task Atoms; a Task Atom Directory Carrier **may** directly contain **only** Task Atoms; **and** a Task Atom **may** remain standalone without either containing directory.
