# Summary

Define Entity/Occurrent/Event

## Scope

Events as Occurrents.

## Claim

an Event **means** an actual occurrence. a record describing the Event is **not** the Event itself.

## Details

Candidate #6 distinguishes actual occurrences from historical records. CA-R-1745 makes the same distinction for Journal records, but does not define Event itself.
