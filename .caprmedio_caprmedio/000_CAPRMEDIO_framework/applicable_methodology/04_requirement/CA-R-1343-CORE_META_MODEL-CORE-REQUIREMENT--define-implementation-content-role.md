# Summary

Define Implementation Content Role

## Scope

Atom Claims that identify current realizations of accepted specification **or** Method authority.

## Claim

Implementation **means** the Content Role of an Atom Claim that identifies one current realization of accepted specification **or** Method authority.

## Details

A governing Implementation Atom is distinct from the native code, prompt, or other Carrier it identifies. RMED → using O → I expresses production of the realization. Native I can subsequently be an actual-state source; it does not thereby redefine governing RMED. Views derived from I remain non-authoritative Projections.
