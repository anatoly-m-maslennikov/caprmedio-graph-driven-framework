Define Unordered as a Type Value under Scope Unit

## Scope
the Unordered Type value of Scope Units in relation to Local Order among sibling Scope Units.

## Claim

the Scope Unit Type value Unordered **means** the value whose bearer does **not** participate **in** a Local Order among sibling Scope Units.
