# Summary

Define Work Sequence Number

## Scope

Work Sequence Numbers for Plans decomposing one Hub or sharing one top-level Plan container.

## Claim

a Work Sequence Number **means** a mutable ordinal navigation value for a Plan among Plans decomposing the same Hub **or** sharing a top-level Plan container; it does **not** establish execution order.
