Atom/(.Header.Role := Implementation)

## Semantics

An Implementation Atom describes actual implementation: code parts, behavior, structure and rationale. A code specification is optional. Supported facts and inferred explanations remain distinguishable. A specification difference is a neutral observation; assessment determines whether it requires resolution as a Concern.
