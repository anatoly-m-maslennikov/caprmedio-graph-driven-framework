# Provide replayable software Evaluation evidence

Deliver evaluation records that bind the evaluated target and source frontier to the Python and evaluation-tool versions, canonical configuration digest, selected technique, seed or minimized generated case when applicable, outcome, diagnostics, and exact replay command. Store bulky transient runs in Runtime and retain governed summaries only when they satisfy the project's reusable-information criterion.

Make evidence from syntax, formatting, linting, typing, behavioral tests, mutation, fuzzing, contracts, benchmarks, and golden comparisons distinguishable rather than collapsing them into one pass state. A consumer must be able to identify which claim each record supports and the boundary outside which it provides no reliance.

Candidate alignment: CA-E-001, CA-E-002, CA-M-003, CA-D-002, CA-O-003, CA-R-861.
