## Summary

Group Engine MED by Engineering Aspect topics

## Objective

Review and group all eligible Current/Draft MED main subjects and dependencies in the Engineering Aspect branch. Check actual content rather than copying Scope Unit names. Retain justified non-Engineering topics. Use the whole Engine inventory, not only the newly found batch.

## Subtasks

Each subtask is a batch of at most 15–20 minutes. Repeat per Scope Unit; give each subagent one Scope Unit.

- [ ] Review pass one on a same-Scope batch.
- [ ] Fix findings and prepare or refine the affected Drafts.
- [ ] Run independent pass two on the corrected batch.
- [ ] Fix pass-two findings and recheck affected earlier criteria.
- [ ] Record a small Work Report and thin coverage entries.

## Definition of Done

Every eligible MED source has an evidenced topic disposition and any correction has a Draft or the applicable authorized topic-only receipt. Tasks track work; specification changes belong in RMEDO. No runtime implementation is performed here.
