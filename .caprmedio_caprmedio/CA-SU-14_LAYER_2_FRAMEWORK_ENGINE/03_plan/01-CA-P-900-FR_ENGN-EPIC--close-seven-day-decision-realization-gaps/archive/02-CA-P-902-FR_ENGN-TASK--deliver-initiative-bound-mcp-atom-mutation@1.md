# Deliver Initiative-bound MCP Atom mutation

WHEN CA-P-901 is Done, THE Assignee MUST deliver one installed project-local MCP mutation gateway that delegates every CAPRMEDIO Markdown Atom mutation to its canonical Atom Tool under one sealed human-origin Initiative and rejects direct mutation outside that gateway.

## Scope

`(Atom ID IN (CA-R-1093, CA-R-1105, CA-R-863, CA-R-864, CA-R-865, CA-R-866, CA-R-867, CA-R-868, CA-R-869, CA-R-870))`

## Definition of Done

THE Task is NOT DONE IF (CA-P-901 is not Done OR ANY create, update, move, archive, promote, upgrade, replacement, atomic, or bulk CAPRMEDIO Markdown Atom mutation can apply through direct Tool execution OR the installed MCP surface does not preserve the operator's Initiative input, stable action identity, exact target set, expected Revision or digest, and canonical Tool result OR a successful mutation can be reported before durable `COMMIT_TRIGGER` acknowledgement OR a stale, conflicting, partial, widened, or failed mutation can be reported as success OR Finder operations can mutate OR fresh installed end-to-end tests do not prove singular and bulk behavior, concurrent conflict rejection, direct-apply rejection, and recovery without changing unrelated work).

## Details

Keep MCP limited to discovery, transport validation, delegation, and result transport. Keep target resolution, preconditions, lifecycle semantics, mutation, rollback, and success state in the canonical Atom Tool. Update the native Tool apply boundary, create the provider-neutral MCP service carriers, publish one verified installed release, and preserve dry-run access for direct Doer inspection.
