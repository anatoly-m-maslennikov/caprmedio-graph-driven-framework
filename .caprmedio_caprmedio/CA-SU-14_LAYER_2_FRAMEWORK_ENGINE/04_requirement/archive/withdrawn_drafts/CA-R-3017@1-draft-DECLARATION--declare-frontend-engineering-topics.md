## Summary

Declare Frontend Engineering topics

## Claim

### Prose Claim

Frontend Engineering is an Engineering Development aspect with these narrower topics:

- Libraries and Frameworks: selecting frontend libraries, frameworks and build tools.
- Component Authoring: writing Svelte components and TypeScript frontend code.
- Code Style: frontend source organization, formatting and responsibility boundaries.

These are topics, not Scope Units. Keep Visual Design, SQL authoring and interface contracts under their existing topics. Naming a library does not move all of its UI behavior into the library-selection topic.
