# Define the PROGRAMMATIC Feature scope

PROGRAMMATIC owns exactly three immediate unordered Feature Scope Units: `TOOLS`, `APPS`, and `MCP`. It owns deterministic and otherwise programmatic Framework Engine behavior, interfaces, and realizations; it does not own agent reasoning or Skill procedures.
