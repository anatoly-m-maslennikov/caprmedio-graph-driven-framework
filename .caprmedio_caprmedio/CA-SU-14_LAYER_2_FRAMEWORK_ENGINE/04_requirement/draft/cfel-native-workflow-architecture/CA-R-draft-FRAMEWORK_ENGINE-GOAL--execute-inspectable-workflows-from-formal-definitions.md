## Summary

Execute inspectable Workflows from formal definitions

## Claim

### Prose Claim

PROGRAMMATIC provides native execution and inspection of reusable Workflows whose formal definitions determine their behavior, with explicit outputs, waiting states and failures.

## Details

This is a proposed component Goal. It does not replace the Project Goal or claim that a Workflow Engine is installed. The architecture Methods in this package propose how to realize it. Existing configurability, Operator control and execution-observability Goals remain applicable.
