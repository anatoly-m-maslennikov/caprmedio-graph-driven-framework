# Ingest an external Analysis

the framework **must** provide one deterministic Tool that imports an external review **or** Analysis into a provenance-preserving envelope, identifies its exact target frontier, **and** prevents the imported claims from becoming accepted project authority **without** a separate governed adoption decision.
