# Summary

Supply active TOOLS to MCP

## Scope

PROGRAMMATIC behavior governing MCP.

## Claim

MCP must project one callable frontier from installed code and generated registration configuration, validate canonical machine-invocation contracts, omit disabled entries, report invalid configured capabilities explicitly, and delegate unchanged through the shared backend API. Internal connectors and helper modules do not become callable merely because their code exists. Direct read or query calls do not require a Workflow Orchestrator wrapper. Source Atoms do not select the runtime frontier.
