# Discover active Tool units

MCP must discover its complete enabled Tool surface from installed code and generated registration configuration. Project settings may disable exact public names. Atom status, Subjects, Tool-folder discovery and the current Project graph do not determine runtime exposure. Unlisted implementation helpers do not become MCP tools merely because their files exist.
