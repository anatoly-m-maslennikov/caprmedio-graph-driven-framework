# Prove the installed Codex plugin end to end

`CODEX_PLUGIN` **must** retain replayable evidence from a fresh Codex conversation using the locally installed package that proves plugin discovery **and** activation, GRAPH_UI access **and** navigation, bounded graph-context transfer, expected Skill **and** Tool routing, installed-resource resolution, permission **and** confirmation behavior, supported boundary cases, **and** non-activation for unsupported requests. Source-package validity, marketplace availability, successful installation, **and** observed runtime invocation **must** remain separate reported outcomes.
