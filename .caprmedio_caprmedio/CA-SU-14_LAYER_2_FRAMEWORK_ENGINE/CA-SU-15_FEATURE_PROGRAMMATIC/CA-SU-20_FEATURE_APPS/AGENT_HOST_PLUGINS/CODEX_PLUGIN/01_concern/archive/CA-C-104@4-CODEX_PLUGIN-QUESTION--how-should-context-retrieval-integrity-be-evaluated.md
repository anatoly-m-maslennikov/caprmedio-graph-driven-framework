# How should context-retrieval integrity be evaluated?

This Concern is derived from CA-A-060 and concerns CA-R-1104, CA-M-199, and
the current direct acceptance boundary in CA-E-317.

HOW should CAPRMEDIO evaluate retrieval coverage, leakage, provenance,
replayability, latency, token cost, and authority contamination before any
heuristically retrieved context may enter governed Codex work?
