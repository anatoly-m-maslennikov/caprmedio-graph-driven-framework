# Applied SPEC Layer

## Purpose

Own CAPRMEDIO product behavior, outcomes, and framework-facing contracts that
are not universal META principles or artifact-governance rules.

## Boundaries

META owns universal framework semantics. GOV owns carrier structure,
validation, and lifecycle. TOOL, SKILL, IMPL, and OPS own their respective
realization concerns. The external installed framework view remains isolated
under `000_caprmedio_framework`.
