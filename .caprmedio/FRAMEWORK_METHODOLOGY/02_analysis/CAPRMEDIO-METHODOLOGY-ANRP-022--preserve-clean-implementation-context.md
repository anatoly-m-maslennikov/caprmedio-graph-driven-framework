# Preserve clean Implementation context

When an LLM investigates native Implementation to determine current behavior, embedded requirements, business rationale, intended behavior, or CAPRMEDIO traceability can contaminate that context and cause intended meaning to be mistaken for operative reality. Keeping normative meaning in CAPRMEDIO Atoms and traceability in Journals and Projections preserves a cleaner source for determining what the Implementation currently does.
