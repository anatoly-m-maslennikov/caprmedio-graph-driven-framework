# Provide Project Settings Projection skill

The framework must provide `ca-project-settings` as the thin operator-facing Skill that checks and rebuilds the Project Settings Map and Project Settings Projections through their registered deterministic Tool, routes semantic changes to the owning RMED Atoms, and never edits either output Projection, authors effective values independently, or embeds executable Tool logic.
