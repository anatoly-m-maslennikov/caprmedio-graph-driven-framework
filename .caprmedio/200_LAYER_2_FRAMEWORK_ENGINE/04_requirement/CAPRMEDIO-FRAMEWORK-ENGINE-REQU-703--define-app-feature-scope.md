# Define the APP Feature scope

The FRAMEWORK_ENGINE Feature with scope `app`, full name `APP`, and prefix `APP` owns the one local CAPRMEDIO application: its source indexer, rebuildable derived database sourced from governed Atoms and Journals, local read-only server, and interconnected web pages.
