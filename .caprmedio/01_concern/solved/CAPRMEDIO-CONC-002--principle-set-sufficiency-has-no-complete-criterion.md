# Principle-set sufficiency has no complete criterion

CAPRMEDIO cannot establish a sufficient criterion that proves the Project Principle set complete because undiscovered project-wide invariants cannot be ruled out. This Concern is solved by treating parent coverage as necessary but insufficient and admitting a new Principle whenever a distinct project-wide invariant is discovered.
