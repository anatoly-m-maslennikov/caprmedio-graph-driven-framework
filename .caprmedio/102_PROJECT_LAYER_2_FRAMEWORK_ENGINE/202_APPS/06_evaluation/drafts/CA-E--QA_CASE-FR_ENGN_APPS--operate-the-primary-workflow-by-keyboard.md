# Operate the primary App workflow by keyboard

Given the App's primary operator workflow, complete it using only a keyboard. Verify visible focus, meaningful control names and roles, predictable order, status announcements, reachable error recovery, and no pointer-only action.

Record the browser and assistive-technology boundary used; automated checks may support but cannot replace this interaction case.

Candidate alignment: CA-E-001, CA-E-002, CA-D-002, CA-R-819.
