# Complete one installed automatic commit end to end

Given a verified self-contained installed Tool release, an enabled asynchronous Codex intake Hook, a running repository service, and one representative Git-admitted project edit, run the live path to quiescence. Verify the same installed release performs durable intake, frontier reconciliation, context sealing, Journal append, and Git commit; the commit and Journal receipts agree; no source-tree import occurs; and the blocked-action and dead-letter places are empty afterward.

The case fails on source-only success, Hook delay, missing receipt, inconsistent provenance, uncommitted governed work, installation drift, or any remaining blocked action.

Candidate alignment: CA-E-001, CA-E-002, CA-D-001, CA-R-827, CA-R-861.
