# CAPRMEDIO framework identity

The canonical framework name is **CAPRMEDIO**. It expands to **Concern–Analysis–Plan–Requirement–Method–Evaluation–Delivery–Implementation–Ops**, matching the nine governed Content roles.

The model may be presented as **CAP · RMED · IO**:

- CAP is Concern, Analysis, and Plan;
- RMED is the distributed Specification formed by Requirement, Method,
  Evaluation, and Delivery; and
- IO is the native Implementation and its enacted Ops feedback.

The public outcome-oriented logline remains **The Vibe-Code-to-Production Framework**. Public documentation, project metadata, repository identity, package identity, installed methodology, and user-facing commands must converge on CAPRMEDIO through a governed migration. Historical evidence may retain prior names and URLs when required for provenance.
