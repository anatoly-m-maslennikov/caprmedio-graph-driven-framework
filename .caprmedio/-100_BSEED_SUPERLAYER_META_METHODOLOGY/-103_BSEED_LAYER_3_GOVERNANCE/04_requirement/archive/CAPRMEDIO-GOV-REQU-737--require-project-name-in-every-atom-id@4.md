# Require Project identity prefix in every Atom ID

Every assigned Atom ID begins with the Project's separately registered uppercase identity prefix as `<PROJECT_PREFIX>`; omission, mismatch with the owning Project, and per-Carrier substitution are invalid. This Project identity prefix is not a Scope Unit filename `scope_path_name`.
