# Centralize Plan carriers by default

GOVERNANCE must place every Plan carrier in the single project-level `.caprmedio/03_plan/` directory by default; a configured project exception may select another location, while each Plan's governed scope remains explicit in the carrier rather than partitioning Plan storage.
