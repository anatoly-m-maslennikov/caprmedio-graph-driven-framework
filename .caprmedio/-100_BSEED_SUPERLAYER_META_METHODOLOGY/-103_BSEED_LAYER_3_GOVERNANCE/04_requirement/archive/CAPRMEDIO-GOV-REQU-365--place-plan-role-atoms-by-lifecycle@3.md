# Place Plan-role Atoms by lifecycle

A draft Plan-role Atom MUST live under `drafts/`, an active Plan-role Atom MUST live directly in its role directory or containing Epic, a done Plan-role Atom MUST live under `done/`, and an archived Plan-role Atom MUST live under `archive/`.
