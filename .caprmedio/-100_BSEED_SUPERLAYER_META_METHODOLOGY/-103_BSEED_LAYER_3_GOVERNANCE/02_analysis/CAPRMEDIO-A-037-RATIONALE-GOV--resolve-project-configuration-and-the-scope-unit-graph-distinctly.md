# Resolve Project Configuration and the Scope Unit Graph distinctly

Project Configuration selects and parameterizes project operation through a human-editable native Atom, while Project Scope Unit Graph Projections expose derived current structure and effective state without authority. Treating both as settings would collapse source authority and generated views into competing writable carriers.
