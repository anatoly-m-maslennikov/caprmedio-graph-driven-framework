# Resolve Framework and Project Settings separately

CAPRMEDIO skills resolve Framework Settings through the governed external
binding for `atom_id: CAPRMEDIO-I-001` and its native Carrier locator, and
resolve Project Settings through its generated control-root Projection address,
without substituting either carrier for the other.
