# Resolve Project Configuration and Graph State separately

CAPRMEDIO skills resolve Project Configuration through the governed external binding for `atom_id: CAPRMEDIO-I-001` and its native Carrier locator, and resolve Project Graph State through its registered generated Projection addresses, without substituting a Projection for configuration authority or treating the Configuration Atom as derived graph state.
