# Register Boundary Requirement Type

GOV registers `boundary` as the internal Requirement Type for one explicit current limit on the applicability, support, availability, or ownership claimed by a project. A Boundary states where current project authority stops; it is not a desired outcome expressed by the default `requirement` Type, an externally imposed `constraint`, an endpoint `contract`, or a selected realization Method. Its canonical class short name is `BOUNDARY`.
