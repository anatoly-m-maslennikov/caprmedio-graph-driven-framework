# Define PROJECT scope

PROJECT owns the concrete Project topology, immediate Project Layer scopes and Contracts, Project Adaptation, the Project Configuration Atom, and Atom authority adopted by the current Project. Generated Project Graph State Projections expose that current topology and authority without owning either.
