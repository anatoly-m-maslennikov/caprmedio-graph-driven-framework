# Register Project Configuration Atom identity

GOV must register `CAPRMEDIO-I-001` as the `atom_id` of the native Project
Configuration Implementation Atom. The governed canonical address
`caprmedio_framework_settings.toml` and the framework-installation symlink are
Carrier locators and do not establish identity. The legacy binding key
`CAPRMEDIO-FRAMEWORK-SETTINGS` is not an Atom ID.
