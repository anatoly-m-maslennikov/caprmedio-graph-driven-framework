# Constraints are externally imposed

Use the Requirement Type `constraint` only when a limitation originates outside the project choice boundary, such as a law, existing DDL, mandated host format, platform limit, or non-negotiable upstream interface. Use Type `requirement` for outcomes selected by the operator or project, Type `implementation_decision` under Method for selected implementation approaches, and Type `contract` under Requirement for obligations across governed endpoints.
