# Mirror every Atom edit in Git

Every Atom creation, accepted refinement, relocation, archival, or replacement must be committed to Git. Git preserves repository snapshots and Implementation changes as a secondary loss-prevention mirror but does not replace the Work Journal as canonical governed provenance.
