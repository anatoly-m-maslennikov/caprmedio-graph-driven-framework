# Validate active RMEDO relation-target lifecycle

GOV validators must derive every direct relation target's lifecycle from canonical placement and reject an active RMEDO carrier when any authored target is not active. Inverse typed relations are derived from the canonical direct edge and must also be rejected when authored in an Atom carrier.
