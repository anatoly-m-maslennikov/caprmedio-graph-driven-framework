# Encode framework settings as a native TOML Atom

`caprmedio_framework_settings.toml` must contain only executable framework-engine settings and human-readable configuration comments in native TOML. It must not embed YAML frontmatter, Artifact identity, revision metadata, relations, rationale, or provenance.
