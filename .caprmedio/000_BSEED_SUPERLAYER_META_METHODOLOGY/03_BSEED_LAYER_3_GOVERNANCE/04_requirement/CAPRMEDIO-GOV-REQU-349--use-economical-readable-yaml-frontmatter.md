# Use economical, readable YAML frontmatter

Every CAPRMEDIO YAML frontmatter schema uses the least syntax and nesting that preserves unambiguous meaning, deterministic parsing and validation, required extensibility, and immediate human readability. Redundant keys, wrappers, discriminators, and values are forbidden, but syntax economy must not depend on ambiguous position or hidden inference.
