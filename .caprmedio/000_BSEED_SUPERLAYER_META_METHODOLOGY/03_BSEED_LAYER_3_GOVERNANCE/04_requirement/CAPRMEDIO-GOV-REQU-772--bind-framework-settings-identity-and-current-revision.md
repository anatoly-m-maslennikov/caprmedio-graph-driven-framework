# Bind Project Configuration identity and current revision

GOVERNANCE must bind `atom_id: CAPRMEDIO-I-001`, the current Revision properties, and
the canonical native Carrier locator in a governed carrier under `.caprmedio/`;
absence, ambiguity, or mismatch of that binding leaves the Project Configuration
Atom's currentness unknown.
