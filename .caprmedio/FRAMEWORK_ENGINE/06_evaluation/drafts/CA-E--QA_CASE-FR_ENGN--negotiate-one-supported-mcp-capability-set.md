# Negotiate one supported MCP capability set

Given one supported and one unsupported MCP protocol revision and capability set, initialize the adapter with each. Verify that the supported peer reaches operation with exactly the negotiated capabilities and that the unsupported peer receives a stable incompatibility response before any capability executes.

Candidate alignment: CA-E-001, CA-E-002, CA-D-001, CA-M-006, CA-R-861.
