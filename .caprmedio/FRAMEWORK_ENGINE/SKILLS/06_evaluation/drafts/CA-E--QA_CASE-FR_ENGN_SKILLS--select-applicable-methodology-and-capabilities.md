# Select applicable Methodology and capabilities

Given one bounded operator request with relevant and irrelevant Methodology, Tools, MCP capabilities, and App interactions available, invoke the Skill. Verify that it loads the relevant authority, selects the smallest sufficient capability set, and neither duplicates nor contradicts canonical meaning in its own instructions.

Candidate alignment: CA-E-001, CA-E-002, CA-M-002, CA-M-005, CA-M-006, CA-R-861.
