# Define the APPS Feature scope

The FRAMEWORK_ENGINE Feature with scope `apps`, full name `APPS`, and prefix `APPS` owns CAPRMEDIO's operator-facing application products, provider-neutral agent capability interfaces, and agent-host plugin packages through exactly three immediate unordered units: `GRAPH_APP`, `MCP`, and `AGENT_HOST_PLUGINS`.
