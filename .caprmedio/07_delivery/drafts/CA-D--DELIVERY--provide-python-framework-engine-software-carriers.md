# Provide Python Framework Engine software carriers

Deliver applicable Framework Engine Tools, App backend services, and MCP components as Python source and installable Python runtime carriers under one declared interpreter and dependency boundary. Identify every admitted non-Python native interface separately with its Operator-accepted reason and integration contract.

Keep the language choice in replaceable realization so CAPRMEDIO governed meaning does not depend on Python syntax, packages, or runtime objects.

Candidate alignment: CA-D-001, CA-D-002, CA-M-005, CA-M-006, CA-R-861.
