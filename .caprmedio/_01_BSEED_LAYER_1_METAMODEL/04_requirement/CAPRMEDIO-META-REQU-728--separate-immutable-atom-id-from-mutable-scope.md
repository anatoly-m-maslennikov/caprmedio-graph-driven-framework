# Separate immutable Atom ID from mutable scope

An accepted Atom has one stable Atom ID independent of its current Carrier filename, Structural scope, Type, and Summary. A draft Atom has no Atom ID. Once operator acceptance assigns `<PREFIX>-<CONTENT_ROLE_LETTER>-<NUMBER>`, later Carrier or scope changes preserve that ID.
