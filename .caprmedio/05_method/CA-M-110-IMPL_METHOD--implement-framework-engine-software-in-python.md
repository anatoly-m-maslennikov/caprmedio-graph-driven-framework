# Implement FRAMEWORK_ENGINE software in Python

Implement applicable CAPRMEDIO FRAMEWORK_ENGINE software—Tools, App backend services, and MCP components—in Python. Declare one supported Python runtime range and use Python's standard library before adding a dependency when both provide the required behavior with comparable clarity and reliability. Use another language only where a native interface requires it or the Operator accepts a documented benefit that exceeds the added boundary cost.

This Method selects the implementation language; it does not make Python part of CAPRMEDIO's discipline-independent governed meaning. A future replacement remains possible through the replaceable-realization principle.

Candidate alignment: CA-R-861, CA-M-005, CA-M-006, CA-D-001, CA-D-002.
