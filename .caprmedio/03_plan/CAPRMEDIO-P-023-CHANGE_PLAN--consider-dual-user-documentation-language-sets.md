# Consider two language sets for User Documentation

1. [ ] Consider maintaining two User Documentation sets: strict FPF-like language and casual language at approximately CEFR A2+/B1.
2. [ ] Define the intended audience and use case for each set.
3. [ ] Decide whether both sets are maintained directly or generated from one governed source.
4. [ ] Define how both sets preserve the same meaning without becoming separate authorities.
5. [ ] Define navigation and naming so a user can deliberately choose the strict or casual set.
6. [ ] Define Evaluation cases for meaning preservation, readability, and language-level consistency.
