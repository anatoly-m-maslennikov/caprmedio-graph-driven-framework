# Define FRAMEWORK_ENGINE Layer scope

FRAMEWORK_ENGINE must own the executable application of FRAMEWORK_METHODOLOGY, including Tools, Skills as wrappers for Methodology authority, routing, graph database and local-server behavior, user interfaces, source-file writes, and every other framework I/O capability. Native executable artifacts remain realizations of this authority rather than CAPRMEDIO authority themselves.
