# Define project scope boundary

PROJECT must be structural level `0` and the Manager of the current project. Its complete active Principle set defines it. It must own its Principles, constitutional Cores governing the complete Layer system, definitions of the complete ordered set of Project Layers, and Contracts among those Layers; delegate all applicable framework meaning and behavior to the Layers; and own no Goal, applicable framework capability, native realization, or I/O.
