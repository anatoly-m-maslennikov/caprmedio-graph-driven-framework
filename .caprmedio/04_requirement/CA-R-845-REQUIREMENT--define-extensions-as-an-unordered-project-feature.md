# Define EXTENSIONS as an unordered Project Feature

EXTENSIONS is an `unordered_unit` Feature owned directly by CAPRMEDIO at Structural level `1`; it has no `local_order` and provides the Project structural container for admitted Extension packages without making an Extension package itself a Structural unit.
