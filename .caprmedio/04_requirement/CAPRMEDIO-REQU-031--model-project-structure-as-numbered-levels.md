# Model project structure as numbered levels

CAPRMEDIO must model the CAPRMEDIO Scope Unit at Structural level `0`, zero or more upstream Structural levels with negative numbers, and zero or more downstream Structural levels with positive numbers; a Structural level groups peer positions but does not itself establish parentage, order, or authority.
