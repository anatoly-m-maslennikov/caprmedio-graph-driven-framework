# Provide Python FRAMEWORK_ENGINE software

CAPRMEDIO must provide applicable FRAMEWORK_ENGINE Software—Tools, App backend
services, and MCP components—as Python realizations under the technical
contract in `pyproject.toml`, table
`tool.caprmedio.framework_engine_software`. The contract is the canonical
carrier for the supported runtime, dependency boundary, and exception-record
locations. This Requirement governs the outcome without duplicating those
technical values. It does not create a Scope Unit and does not apply to Skills.
