# Derive one effective Operator priority order

Before CAPRMEDIO selects a project trade-off, it must derive exactly one effective priority order for the affected scope and project stage from current Operator-established priorities, applicable authority, and non-negotiable constraints. When no unique applicable order can be derived, CAPRMEDIO must return the selection to the Operators instead of selecting automatically.
