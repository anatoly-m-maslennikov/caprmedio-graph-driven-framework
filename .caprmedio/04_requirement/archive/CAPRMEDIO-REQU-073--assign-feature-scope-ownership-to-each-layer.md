# Assign feature scope ownership to each layer

PROJECT owns canonical Layer scope definitions and inter-Layer Contracts; each Layer owns its canonical Feature scope definitions and inter-Feature Contracts. Equal, overlapping, or different Feature partitions across Layers remain independently owned and are connected only through explicit PROJECT Contracts.
