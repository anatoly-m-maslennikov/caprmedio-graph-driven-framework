# Define project scope boundary

CAPRMEDIO must be Structural level `0` and the Manager of the current project. Its scope is open, expandable, and mutable; the root Intent states its current Goal, which carries the current project scope, and its Stated Capabilities. CAPRMEDIO must own its Principles, constitutional Cores governing the complete Layer system, definitions of the complete ordered set of Project Layers, ordinary RMEDO authority shared by those Layers, and directional relational Atoms whose endpoints cross those Layers; delegate all applicable framework meaning and behavior to the Layers; and own no Intent, applicable framework capability, native realization, or I/O.
