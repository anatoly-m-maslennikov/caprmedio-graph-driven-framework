# Define CAPRMEDIO structural levels

The CAPRMEDIO project must use exactly seven structural levels: Project root `0` as Manager, META Layer `1`, GOV Layer `2`, METHODOLOGY Layer `3`, FRAMEWORK_ENGINE Layer `4`, DOCUMENTATION Layer `5`, and RELEASES Layer `6`.
