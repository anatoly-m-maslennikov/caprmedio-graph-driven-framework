# Define Framework composition

The CAPRMEDIO Framework must consist of FRAMEWORK_METHODOLOGY plus FRAMEWORK_ENGINE. OPERATOR_DOCUMENTATION, CORE_EXTENSIONS, and RELEASES are downstream Project Layers; COMMUNITY_EXTENSIONS and FIELD are direct Project Features. None of these downstream units is a constituent of the Framework itself.
